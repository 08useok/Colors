## 출시 당일 진행 순서

1. 출시 대상 버전·기능을 확정하고 추가 변경을 마감한다.
2. 반영 직전 메인 코드와 운영 저장소를 백업하고 복원 절차를 확인한다. SQLite가 실행 중이면 일관된 DB 백업 방식을 사용한다. 비밀번호·복구 코드·저장 데이터를 공개 저장소에 넣지 않는다.
3. 메인·베타 공유 계정과 진행도 정책에 맞춰 데이터 연결을 구현·검증한다. 기존 계정을 덮어쓰거나 베타 시험 데이터를 자동 병합하지 않는다.
4. 검증된 시즌 8 콘텐츠를 메인에 연결한다. 로스터·해금·모드·스킨·모션·버전과 캐시를 함께 점검한다.
5. Ego에서 로그인→대전→퀘스트→보상 수령→전적·랭킹→재접속을 검증한다. 기존 메인 진행도와 베타 계정의 호환, 보상 중복 수령 방지를 확인한다.
6. 메인 패치노트를 최종 구현과 비교한다. 캐릭터 밸런스에는 캐릭터 자체 수치·기술만 적고 AI 변경은 제외한다. 예정 표기를 실제 출시 정보로 바꾸는 것은 공개 시점에 한다.
7. 최종 검사 통과 후 공개하고 실제 공개 주소에서 저장·로그인·보상을 다시 확인한다.
