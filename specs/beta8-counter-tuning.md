# 베타 0.8.45 · 남은 역전 상성 조정

## 적용 기준

기존 역할과 기술을 유지하는 방향으로 조정했다. 17개 목표 연결 모두 시험 점수율50% 초과를 우선하며, 사용자가 별도로 확정한 살몬→골드는120전 전승을 유지한다. 모든 연결100% 또는 각자 단 한 명에게만 전승하는 기준까지 달성했다는 뜻은 아니다.

블루 체력을10192로 올리는 등의 광범위한 탐색 후보는 적용하지 않았다. 모든 기존 캐릭터의 체력·이동속도·일반 공격 피해는 유지했다. 후보 JSON/탐색 도구는 검토 기록이며 제품 설정이 아니다.

- 기존 투사체 처리가 궁 밀치기 수치를9로 나누지만 같은 대상은 한 번만 맞혀, 실제 밀치기가 설명의1/9이었다. 베타8만 전체 거리를 적용하도록 수정했다. 벽/경계/저항에 따른 기존 이동 제한은 유지한다.
- 크리스탈의 분석 완료 즉사가 남은 체력만큼 일반 피해를 주어 피해 감소 보호막에 막히던 문제를 수정했다. 베타8에서는 피해 감소를 무시한다. 무적·사망·부활·시전자 사망 해제 같은 기존 공통 처리까지 우회하지 않는다.
- 애저·크림슨 봇의 탱커 접근 사용 거리는3타일로 유지한다. 수동 사용은 제한하지 않는다.
- 시안 궁 피해5200, 살몬 피해3000+착지600 등 이전에 확정한 수치는 유지한다.
- 메인과 베타7에는 이번 베타8 옵션/수치 덮어쓰기를 적용하지 않는다. 설명과 궁 게이지는 최신 충전량에 맞춘다.

136쌍 ×120회, 총16320경기에서 **목표17연결 모두 우세**, 전승은9연결이다.

| 이전에 역전됐던 연결 | 현재 승/패/무 | 점수율 |
|---|---|---:|
| 시안 → 핑크 | 120/0/0 | 100% |
| 골드 → 그린 | 120/0/0 | 100% |
| 라벤더 → 크림슨 | 120/0/0 | 100% |
| 크리스탈 → 레드 | 118/2/0 | 98.3% |

- 아이보리→살몬, 살몬→골드 모두120전 전승 유지.
- 이웃 관계는 애저→라벤더93승26패1무(점수율77.9%), 크림슨→크리스탈77승43패(64.2%)로 여전히 목표 방향이 우세하다.
- 전체100%/유일 상성까지 맞추려면 추가 기술 설계나 큰 수치 변경이 필요할 수 있어 이번 결과와 구분한다. 실제 이용자의 승률을 보장하지 않는다.
