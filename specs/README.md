## 작성 규칙

- 대표 파일에는 기능 범위, 기준 코드와 관련 상세 문서를 기록한다.
- 세부 수치와 긴 동작 설명은 기존 상세 문서에 유지한다.
- 알파 기본 게임과 베타 테스트 수치는 반드시 구분한다.
- 실제 수치의 최종 기준은 설정 파일과 실행 코드다.
- 아직 구현되지 않은 내용은 `계획`으로 명시한다.
