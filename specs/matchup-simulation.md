# 궁극기 포함 상성 시뮬레이션

메인 로비의 상성표는 민트 포함 13종의 **궁극기 포함 1대1 근사 모델** 결과다.
실제 게임 엔진이나 브라우저를 실행한 결과, 플레이어 실전 승률 또는 팀전 종합 순위가 아니다.
베타 테스트 페이지의 별도 캐릭터 설정에는 적용하지 않는다.

## 실행 및 갱신

프로젝트 루트에서 실행한다. Node.js 내장 모듈만 사용한다.

```powershell
npm.cmd run simulate:matchups -- --write
npm.cmd run simulate:matchups -- --check
npm.cmd run check:matchups
npm.cmd run check
```

- 구현: [시뮬레이터](../tools/simulate-matchups.mjs)
- 입력: [메인 캐릭터 설정](../src/config/characters.js), [전투 구현](../src/main.js)
- 출력: [결과 원본](matchup-results.json), [궁극기 전후 비교](matchup-comparison.md), [로비 HTML](../index.html)의 상성표 본문
- `--write`: 시뮬레이션 후 원본과 표를 함께 갱신한다.
- `--check`: 재실행 결과가 저장된 결과 및 표와 같은지 검사한다. 파일은 변경하지 않는다.
- 결과에는 설정·전투 소스·시뮬레이터의 SHA-256을 남긴다. 전투 코드 변경 후에는 모델의 규칙도 검토하고 재생성한다.

## 반영 범위와 한계

- 일반 공격의 이동 투사체, 연속 타격, 산탄 간격, 재장전, 독, 감속, 장판을 모델링한다.
- 레드의 사거리는 설정의 `attackRange=5.5`가 아니라 현재 `getAttackRange()`가 실제 사용하는 `attackDepth=6`을 읽는다. 두 타격의 시간·피해도 코드에서 읽는다. 게임 밸런스 자체는 변경하지 않는다.
- 그린의 귀환 및 원거리 피해 감소, 퍼플의 독침/약병 교대, 골드의 단계별 분열과 단계당 중복 피해 방지, 민트의 3연사와 고정 발사 방향을 포함한다.
- 오렌지의 직격·폭발·확정 과즙, 샤르트뢰즈의 45/45/5/5% 탄종과 상태 효과를 포함한다. 민트는 적중당 얼음 25, 100 누적 시 2초 이동·공격 봉쇄를 반영한다. 궁극기 포함 모드에서는 민트 장판의 투척 시간·착지 대기·지속 피해·얼음·미끄러짐도 반영한다. 핑크는 자신을 회복하지 않는다.
- **근사 모델**: 게임의 봇 AI를 그대로 실행하지 않는다. 두 캐릭터 모두 같은 거리 유지·조준 정책을 사용한다. 실제 사람의 숙련도, 캐릭터별 수동 조준 전략을 예측하지 않는다.
- 팀 지원·부활, 맵의 일반 수풀·내부 벽·고저차, 자기장, 캐릭터 간 밀어내기, 네트워크 지연, 3D 투척 높이, 시각 효과는 제외한다. 궁극기로 생성한 은신·장판은 반영하며 블루는 전장 경계에서 반사한다. 넉백은 즉시 위치 이동으로 근사한다.
- 전투 규칙은 별도 구현이므로 원본 엔진과 자동으로 모두 동기화되지 않는다. 해시는 변경 감지용이며 규칙의 동등성을 증명하지 않는다.
- 따라서 궁극기·팀전 의존도가 큰 캐릭터나 지형을 활용하는 캐릭터의 실전 유불리와 달라질 수 있다. 600회에는 같은 시드의 위치 교환이 포함되므로 독립적인 실전 표본 600개로 해석하지 않는다.

## 궁극기 모델 및 사용 정책

충전은 실제 메인의 일반 공격 적중 규칙을 따른다. 일반 공격만 실행하는 기준 모드에서는 같은 충전 계산을 하되 사용하지 않는다. 궁극기 피해와 장판 피해는 충전하지 않는다. 골드는 단계별 3·2·1 충전, 공격당 최대 6을 적용한다.

| 캐릭터 | 반영 효과 | 사용 조건 |
|---|---|---|
| 레드 | 8초 피해 60% 감소 | 충전 완료 |
| 그린 | 은신으로 적 표적 획득 중단, 공격·피격 시 노출 | 탄약 0 또는 체력 40% 이하, 탄약이 찰 때까지 공격 대기 |
| 블루 | 1.15초 속도 24 돌진, 경계 반사, 적당 피해 1회·넉백 | 적이 8타일 이내 |
| 시안 | 폭 10·길이 판정 2의 투사체, 피해·넉백 | 적이 궁극기 사거리 안 |
| 크림슨 | 정면 범위 피해·넉백 | 적이 정면 범위 안 |
| 골드 | 0.35초 뒤 시전자 추종 장판, 공격 금지·이동 50% 감소 | 적이 장판 반경 안 |
| 아이보리 | 조준 방향 중심과 대각선 네 곳에 총 5회 투척·장판 | 충전 완료 |
| 샤르트뢰즈 | 6초간 새 탄종에서 무탄 제외, 3종 동일 확률 | 충전 완료, 기존 탄종 대기열 유지 |
| 민트 | 10타일 투척, 속도 14·착지 후 0.08초 대기, 10초 장판 | 충전 완료 |
| 핑크 | 아군 부활 | 1대1에는 아군이 없어 사용하지 않음; 자기 부활을 추가하지 않음 |
| 오렌지·옐로우·퍼플 | 현재 메인 시즌 5에 궁극기 없음 | 후속 베타 시즌 기술은 포함하지 않음 |

모든 발동은 생존·빙결·고장·충전 조건을 확인한다. 숫자는 캐릭터 설정에서 읽으며, 위 표는 현재 설정의 요약이다. 블루 접근 거리와 그린 재장전 대기 등 사용 정책은 시뮬레이터의 가정이다. 정책을 바꾸면 결과도 달라질 수 있다.

`check:matchups`는 별도 충전 완료 상태로 드물게 발동하는 기술도 확인한다. 이 검사 결과는 상성표의 충전 0 경기 수에 포함하지 않는다. 자연 충전으로 한 번도 발동하지 않은 기술은 [비교 문서](matchup-comparison.md)에 명시한다.

## 표 읽기

각 셀의 이름은 상대 캐릭터이며 비율은 행 캐릭터 기준 `(승리 + 무승부 × 0.5) / 경기 수`다.

| 단계 | 점수 |
|---|---|
| 압도적 유리 | 95% 이상 |
| 완전 유리 | 85% 이상~95% 미만 |
| 유리 | 70% 이상~85% 미만 |
| 약간 유리 | 55% 이상~70% 미만 |
| 경합 | 45% 초과~55% 미만 |
| 약간 불리 | 30% 초과~45% 이하 |
| 불리 | 15% 초과~30% 이하 |
| 완전 불리 | 5% 초과~15% 이하 |
| 압도적 불리 | 5% 이하 |

실전에서 승리가 불가능하거나 무조건 이긴다는 뜻이 아니므로 기존의 “완벽한 카운터/불가능” 표현은 사용하지 않는다.
각 행에는 자신을 제외한 12종이 정확히 한 번씩 나타난다. A→B와 B→A의 점수 합은 100%이며 단계도 반대다.
