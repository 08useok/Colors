# 베타 시즌 승리·패배 포즈

## Summary

베타 시즌 경기 결과가 확정되면 결과창을 즉시 표시하지 않고, 플레이한 캐릭터의 전용 승리 또는 패배 애니메이션을 먼저 보여준다. 애니메이션이 끝나면 마지막 포즈를 유지하며 `화면을 클릭하세요` 안내를 표시한다. 사용자가 연출 화면을 클릭했을 때 `다시 하기`와 `나가기` 버튼을 표시한다.

이 기능의 목적은 경기 결과를 캐릭터별 개성이 드러나는 짧은 보상 연출로 전달하면서, 기존 결과 기록·보상·재시작 흐름을 유지하는 것이다.

## Scope

- 베타 시즌 1의 9개 캐릭터
- 쇼다운, Chop Wood, 테이크다운의 결과 화면
- 캐릭터별 승리·패배 애니메이션
- 결과 연출 화면의 클릭 안내
- `다시 하기`와 `나가기` 버튼 노출
- GLB 애니메이션과 코드 기반 관절 포즈의 공통 재생 규칙

## 결과 판정

| 모드 | 승리 포즈 | 패배 포즈 |
|---|---|---|
| 쇼다운 | 최종 순위 1~4위 | 최종 순위 5~10위 |
| 테이크다운 | 최종 순위 1~4위 | 최종 순위 5~10위 |
| Chop Wood | 플레이어 팀 승리 | 플레이어 팀 패배 |
| 훈련장 | 사용하지 않음 | 사용하지 않음 |

승리 판정은 기존 전적과 β 크레딧 지급 기준을 변경하지 않는다. 결과 포즈는 이미 확정된 결과를 표현할 뿐 승패를 다시 계산하지 않는다.

## 결과 흐름

1. 경기 종료 조건을 확정한다.
2. 승패, 순위, 전적, 트로피, 코인과 β 크레딧을 기존 규칙대로 한 번만 기록한다.
3. 이동, 조준, 공격, 궁극기와 이모트 입력을 차단한다.
4. 전투 카메라를 결과 캐릭터 중심 연출 카메라로 전환한다.
5. 승리 시 2.5초, 패배 시 1.5초 동안 캐릭터 전용 애니메이션을 재생한다.
6. 애니메이션이 끝나면 마지막 프레임을 유지하고 `화면을 클릭하세요`를 표시한다.
7. 사용자가 연출 화면을 클릭하면 `다시 하기`와 `나가기` 버튼을 표시한다.
8. 버튼이 표시된 뒤에도 캐릭터의 마지막 포즈를 배경에 유지한다.

연출 재생 중 사용자가 화면을 클릭하면 애니메이션을 마지막 프레임으로 즉시 이동하고 버튼을 표시한다. 버튼은 사용자가 클릭하기 전에는 자동으로 나타나지 않는다.

## 결과 화면

- 캐릭터와 포즈가 주요 시각 요소가 되도록 카메라를 가까이 배치한다.
- 기존 순위, 트로피 변화량, 코인, 피해량, 연승과 β 크레딧 문구는 유지한다.
- 결과 정보는 포즈를 가리지 않는 영역에 표시한다.
- 연출 재생 중에는 `화면을 클릭하여 건너뛰기`를 표시한다.
- 연출 종료 후에는 `화면을 클릭하세요`를 표시한다.
- 첫 클릭 후 안내 문구를 숨기고 `다시 하기`, `나가기` 버튼을 표시한다.
- 버튼을 직접 클릭했을 때 결과 화면 클릭 처리와 버튼 동작이 중복 실행되지 않아야 한다.

### 다시 하기

- 기존 모드의 재시작 규칙을 그대로 사용한다.
- 쇼다운은 동일한 쇼다운 진입 흐름으로 돌아간다.
- 테이크다운은 기존 캐릭터 선택 또는 매치메이킹 흐름을 사용한다.
- Chop Wood는 새 Chop Wood 경기를 시작한다.
- 이전 결과 포즈의 모델, 애니메이션, 카메라와 이벤트 상태를 정리한다.

### 나가기

- 멀티플레이 연결이 있으면 기존 방식대로 연결을 종료한다.
- 전투 맵과 결과 포즈용 객체를 정리한다.
- 로비 카메라, HUD와 입력 상태를 복구한다.
- 기존 결과 화면의 닫기·로비 복귀 동작과 충돌하지 않아야 한다.

## 캐릭터별 포즈

| 캐릭터 | 승리 애니메이션 | 패배 애니메이션 |
|---|---|---|
| Red | 복싱 가드를 잡은 뒤 양팔을 높이 들어 올린다. | 휘청인 뒤 한쪽 무릎을 꿇고 고개를 숙인다. |
| Green | 돌아오는 부메랑을 잡아 한 바퀴 돌리고 자신 있게 선다. | 부메랑을 놓친 뒤 빈손을 바라보고 고개를 숙인다. |
| Blue | 빠른 연속 손동작을 보여준 뒤 여유 있게 선다. | 손을 털며 뒤로 물러난 뒤 주저앉는다. |
| Orange | 오렌지를 위로 던졌다가 받아 들고 자랑한다. | 터진 오렌지를 바라보다가 어깨를 늘어뜨린다. |
| Yellow | 전기 스파크를 발생시키며 공구를 높이 들어 올린다. | 감전된 듯 몸을 떤 뒤 힘없이 쓰러진다. |
| Cyan | 알약을 손에서 돌린 뒤 수상한 미소를 짓는다. | 빈 약통을 확인하고 풀이 죽은 자세로 앉는다. |
| Purple | 독병을 들어 보인 뒤 우아하게 인사한다. | 독병을 떨어뜨리고 비틀거리며 한쪽 무릎을 꿇는다. |
| Pink | 음표 효과에 맞춰 짧게 춤춘 뒤 손을 흔든다. | 마이크를 내리고 풀이 죽어 앉는다. |
| Crimson | KO 스트레이트를 날린 뒤 챔피언 자세를 취한다. | 가드를 유지한 채 한쪽 무릎을 꿇고 고개를 숙인다. |

포즈 중 캐릭터의 소품은 손이나 몸에서 분리되지 않아야 한다. 장착 스킨과 스킨 장식도 결과 포즈에 그대로 적용한다.

## 애니메이션 규칙

- 승리 애니메이션의 총 재생 시간은 2.5초다.
- 패배 애니메이션의 총 재생 시간은 1.5초다.
- 애니메이션은 한 번만 재생하고 마지막 프레임에서 정지한다.
- 이동·공격 애니메이션이 재생 중이면 결과 애니메이션으로 자연스럽게 전환한다.
- 결과 애니메이션이 시작되면 이전 걷기, 정지, 공격 액션은 더 이상 관절을 덮어쓰지 않는다.
- Blue, Cyan, Pink처럼 GLB 모델을 사용하는 캐릭터는 전용 결과 클립을 우선 사용한다.
- 전용 GLB 클립이 없거나 로드에 실패하면 동일한 콘셉트의 코드 기반 뼈 포즈를 사용한다.
- 절차적 모델 캐릭터는 기존 관절 그룹을 사용해 코드 기반 애니메이션을 재생한다.
- 프레임 속도와 관계없이 같은 시간에 같은 단계까지 진행되도록 `dt` 기반으로 보간한다.
- 애니메이션 건너뛰기는 최종 관절·소품·모델 위치를 마지막 프레임과 동일하게 적용한다.

## 카메라와 무대

- 결과 카메라는 캐릭터 전신과 주요 소품이 보이는 거리에서 시작한다.
- 승리 포즈는 캐릭터를 약간 아래에서 올려다보는 각도를 사용할 수 있다.
- 패배 포즈는 캐릭터가 바닥에 닿거나 무릎 꿇는 자세가 잘리지 않아야 한다.
- 포즈 재생 중 전투 카메라의 마우스 회전과 휠 확대를 차단한다.
- 전투 맵 정리 때문에 포즈 캐릭터가 사라지지 않아야 한다. 결과용 캐릭터 표현이 준비된 뒤 전투 객체를 정리한다.
- 결과 화면 종료 시 결과 카메라와 임시 조명·효과를 모두 제거한다.

## 사운드와 효과

- 기존 승리 SFX와 패배 SFX를 결과 애니메이션 시작 시 한 번만 재생한다.
- Pink의 음표, Yellow의 전기, Crimson의 펀치 궤적처럼 포즈 이해에 필요한 짧은 시각 효과를 허용한다.
- 결과 포즈 전용 BGM, 음성 대사와 신규 외부 음원은 이번 범위에 포함하지 않는다.
- 시각 효과는 결과 정보와 버튼을 가리지 않아야 한다.

## 상태와 정리

결과 연출은 최소한 다음 상태를 구분해야 한다.

- `playing`: 애니메이션 재생 중이며 클릭하면 건너뛴다.
- `waitingForClick`: 마지막 포즈와 클릭 안내를 표시한다.
- `actionsVisible`: 다시 하기와 나가기 버튼을 표시한다.
- `closed`: 결과 객체와 이벤트를 정리한 상태다.

동일 경기에서 결과 기록, 보상 지급, 결과 SFX와 포즈 시작은 각각 한 번만 실행한다. 결과 화면을 닫거나 새 경기를 시작하면 포즈 진행 시간, 클릭 상태와 임시 객체를 초기화한다.

## Edge Cases

- 결과 확정과 동시에 클릭해도 기록 또는 보상이 중복 처리되지 않는다.
- 빠르게 여러 번 클릭해도 버튼은 한 번만 표시된다.
- 포즈 애니메이션 재생 중 브라우저 탭이 백그라운드로 이동해도 복귀 후 시간이 비정상적으로 건너뛰거나 반복되지 않는다.
- GLB 클립 로딩 실패 시 기본 포즈로 전환하고 결과 진행을 막지 않는다.
- 캐릭터 모델 또는 스킨 리소스 로딩 실패 시 기본 캐릭터 표현으로 결과 화면을 계속 표시한다.
- 플레이어 사망 후 관전하다 결과가 확정된 경우에도 플레이어가 사용한 캐릭터의 패배 포즈를 표시한다.
- 멀티플레이 연결 종료 또는 호스트 메시지가 중복 도착해도 결과 화면을 두 번 만들지 않는다.
- `다시 하기`를 눌러 캐릭터 선택을 취소해도 결과 화면이 정지된 전투 화면처럼 남지 않는다.
- `나가기`를 누르면 전투 입력, 포인터 잠금, 카메라와 HUD가 로비 상태로 복구된다.

## Dependencies

- 결과 판정과 기록: `src/main.js`의 `checkEndState()`, `recordGameResult()`
- 결과 UI: `index.html`의 결과 오버레이와 `src/main.js`의 결과 버튼 이벤트
- 캐릭터 애니메이션: `updateFighterAnimation()`, GLB `AnimationMixer`
- 전투 정리: `clearBattleMap()`
- 베타 시즌 전환: `specs/beta-season-transition.md`
- 모드별 결과 규칙: `specs/03-combat-results.md`

## Non-goals

- 알파 시즌 결과 화면에 즉시 적용
- 훈련장 승리·패배 포즈
- 결과 포즈가 승패, 순위 또는 보상 수치를 변경하는 기능
- 결과 포즈 전용 BGM, 음성 대사 또는 신규 외부 음원
- 포즈 선택·구매·장착 기능
- 다른 플레이어나 AI 캐릭터의 포즈를 동시에 보여주는 단체 결과 화면
- 이 명세 작성과 동시에 애니메이션을 구현하거나 배포하는 작업

## Acceptance Criteria

- [ ] 베타 시즌의 쇼다운·테이크다운 1~4위에 승리 포즈가 표시된다.
- [ ] 베타 시즌의 쇼다운·테이크다운 5~10위에 패배 포즈가 표시된다.
- [ ] Chop Wood 팀 승리에는 승리 포즈, 팀 패배에는 패배 포즈가 표시된다.
- [ ] 훈련장에서는 결과 포즈가 표시되지 않는다.
- [ ] 9개 캐릭터가 표에 정의된 서로 다른 승리·패배 애니메이션을 사용한다.
- [ ] 승리 애니메이션은 2.5초, 패배 애니메이션은 1.5초 동안 재생된다.
- [ ] 애니메이션은 한 번 재생된 뒤 마지막 프레임에서 정지한다.
- [ ] 재생 중 화면을 클릭하면 즉시 마지막 포즈로 이동한다.
- [ ] 클릭 전에는 다시 하기와 나가기 버튼이 표시되지 않는다.
- [ ] 애니메이션 종료 후 클릭 안내가 표시되고 마지막 포즈가 유지된다.
- [ ] 화면을 클릭하면 다시 하기와 나가기 버튼이 한 번만 표시된다.
- [ ] 포즈 재생 중 이동, 조준, 공격, 궁극기, 이모트와 카메라 조작이 차단된다.
- [ ] 결과 정보와 기존 승리·패배 SFX가 유지된다.
- [ ] 전적, 트로피, 코인과 β 크레딧이 한 경기당 한 번만 처리된다.
- [ ] 장착한 스킨과 장식이 결과 포즈 캐릭터에 적용된다.
- [ ] GLB 결과 클립이 없거나 실패하면 코드 기반 포즈로 결과가 계속 진행된다.
- [ ] 다시 하기는 현재 모드의 기존 재시작 흐름을 실행한다.
- [ ] 나가기는 전투 객체를 정리하고 로비 상태를 복구한다.
- [ ] 결과 화면을 여러 번 클릭해도 이벤트, 보상 또는 UI가 중복 생성되지 않는다.
- [ ] 새 경기 시작 후 이전 결과 포즈, 카메라, 효과와 입력 차단 상태가 남지 않는다.

## Validation

1. 9개 캐릭터 각각으로 승리·패배 결과를 강제로 만들어 총 18개 포즈를 확인한다.
2. 쇼다운, 테이크다운과 Chop Wood에서 모드별 승패 판정이 기존 전적과 일치하는지 확인한다.
3. 애니메이션 재생 중 클릭, 종료 후 클릭과 빠른 연속 클릭을 각각 시험한다.
4. 다시 하기와 나가기를 반복해 전투 객체, 카메라, 입력과 결과 UI가 정상 초기화되는지 확인한다.
5. GLB 결과 클립과 코드 기반 대체 포즈를 각각 시험한다.
6. 스킨 장착 상태, 브라우저 백그라운드 전환과 멀티플레이 결과 중복 메시지를 점검한다.
