# 변신 (Transform)

베타 시즌 9 전용. 가젯 출시 전에 들어가는 시스템으로, 브롤스타즈의 하이퍼차지와 비슷하다. 메인 시즌 8과 밸런스 도구(꼬리잡기 검증 등)에는 적용되지 않는다(`transforms: true` 옵션을 켠 베타 경기에서만 동작).

## 공통 규칙

| 항목 | 값 |
|---|---|
| 게이지 | 궁극기 충전량이 쌓일 때 변신 게이지도 함께 찬다 |
| 게이지 1칸 | 궁극기 1.5번 분량 (`chargeMultiplier`) |
| 변신 중 충전 | 변신 게이지는 차지 않는다 (궁극기는 평소처럼 찬다) |
| 지속 시간 | 6초 |
| 발동 | 변신 버튼(궁극기 버튼 아래) 클릭 또는 **F** 키 |
| 발동 불가 | 쓰러짐·빙결·고장(행동 불가) 중, 이미 변신 중 |
| 부활 | 변신 게이지 유지 (궁극기와 같음) |
| 녹아웃 라운드 | 다음 라운드로 변신 게이지 이월 (궁극기는 초기화) |
| 봇 | 게이지가 차면 사거리 안에 적이 있을 때 스스로 변신 |

수치는 `src/config/transforms.js`에서 캐릭터별로 바꾼다.

## 오렌지 — 「껍질이 왜 이렇게 많아?!」

- 바뀌는 능력이 궁극기라서 **궁극기가 충전돼 있어야 변신할 수 있다.**
- 변신 중 궁극기: 오렌지 껍질 **15개**를 거리별로 1·2·3·4·5개씩 배치한다(가까운 줄부터 1개, 먼 줄 5개, 궁극기 사거리를 5등분).
- 껍질은 평소처럼 날아가 멈춘 뒤 되돌아오며 왕복 중 적에게 피해를 준다. 껍질 하나당 1회 적중 피해 **1,000** (갈 때·올 때 각각).
- 15개가 모두 맞으면 최대 15,000.
- 궁극기 재충전 총량은 평소 궁극기(껍질 5개)와 같게 맞췄다(껍질당 재충전 = 기존 × 5/15).

## 샤르트뢰즈 — 「천사」

- 변신 중 모든 일반 공격이 **Heaven 탄환**이 된다(발동 확률 100%). 평소에는 나오지 않는다.
- Heaven 탄환 피해는 기본 탄 피해와 같다(궁극기 효과 중이면 배율 적용).
- 맞은 적에게 **천사 표식**이 6초 동안 남는다(머리 위 금색 고리).
- 표식이 남은 적이 상대 팀에게 **CC**를 받으면 즉사한다. 처치는 CC를 건 쪽에 기록된다.
- 변신이 끝나도 표식은 남아 있으므로, 변신 후 샤르트뢰즈의 CC탄이나 아군의 CC로 마무리하는 구조다.

### CC로 치는 효과

둔화(옐로 전기·회로, 라벤더 향기, 라즈베리 감옥 범위), 고장(골드 궁극기 장판), 빙결(민트), 속박(라즈베리 덩굴·감옥), 넉백(블루·크림슨·시안·아주르·민트 장판), 크리스탈 분석 속박, 살몬 낚아채기(공중), 샤르트뢰즈 CC탄(독 효과 제외).
무적 중인 적은 즉사하지 않는다.
