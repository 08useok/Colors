# 베타 시즌 4 스펙

## 1. 개요

베타 시즌 4는 베타 전체 테스트 페이지의 기능 목록과 분리된 시즌 전용 기획이다.
샤르트뢰즈, 레드 가드, 중앙 외부 공격 로봇, 플레이어 자연 회복을 중심으로
전투 기능과 UI 변경을 검증하는 것을 목표로 한다.

| 항목 | 내용 |
|---|---|
| 시즌 ID | `beta4` |
| 시작 시점 | 베타 시즌 3 종료 후 |
| 핵심 대상 | 샤르트뢰즈·레드 가드·중앙 외부 공격 로봇·플레이어 회복 |
| 상태 | 검증 대기 |

## 2. 시즌 4 핵심 콘텐츠

### 2.1 샤르트뢰즈

- 샤르트뢰즈 캐릭터를 추가한다.
- 일반 탄환과 구분되는 랜덤 탄환 4종을 구현한다.
- 탄환 중 CC 탄환과 흑사병 즉사탄을 포함한다.
- 특수공격의 지속시간은 6초로 한다.
- 탄환 종류마다 전용 UI 색상을 표시한다.

### 2.2 레드 가드

- 레드 가드에 시즌 4 전용 방어 효과를 적용한다.
- 보호막 지속시간은 8초로 한다.
- 보호막이 받는 피해를 60% 감소시킨다.
- 보호막은 투명한 구형 실드로 표시한다.
- 일반공격 적중 시 궁극기 게이지를 충전한다.

### 2.3 중앙 외부 공격 로봇

- 중앙 외부에 공격 로봇을 배치한다.
- 최대 체력은 9000으로 한다.
- 로봇 머리 위에 현재 체력바를 표시한다.
- 레이저 공격 패턴을 추가한다.
- 피해를 받은 뒤 자연 회복한다.

### 2.4 플레이어 자연 회복

- 플레이어 캐릭터의 자연 회복은 마지막 피해 후 5초가 지나면 활성화한다.
- 활성화 후 1초마다 최대 체력의 10%를 회복한다.

## 3. 시즌 4 범위 제외

골드 러시, 아이스크림 쇼다운, 일일 보상, 주문 이벤트, 일반 상점·스킨 테스트 등
베타 전체 페이지에 이미 존재하는 기능은 시즌 4 신규 기획으로 취급하지 않는다.
