# 베타 0.8.46 · 블루 궁 보호막

0.8.47에서 투사체·궁 충전량을 추가 조정했으며 보호막 동작은 유지했다. [최신 조정·Ego space20 검증](beta8-blue-charge.md)을 참조한다.

- 일반 공격 넉백만 제거한다. 기본 피해와 궁극기의 기존 넉백은 유지한다.
- 궁 사용 준비부터 구르기 종료까지 **70% 피해 감소** 보호막을 적용한다. 피해1000을 받으면300만 적용한다.
- 베타8의 구르기 중 기존 무적을 이 보호막으로 교체한다. 부활 직후 등 별도 무적 시간은 변경하거나 덮어쓰지 않는다.
- 자연 종료·돌진 취소·빙결·행동 불가·사망 시 보호막이 남지 않는다. 상시 보호막/피격 자동 발동/별도 재사용 대기는 추가하지 않는다.
- 훈련장과 공유 대전, 플레이어와 봇에 적용하며 보호막을 파란 구체로 표시한다. 공유 전투에서 이미 감소된 피해를 화면 연결 시 다시 감소시키지 않는다.
- 독안개 등 기존 보호막을 무시하는 환경 피해와 크리스탈의 피해 감소 무시 즉사 규칙은 유지한다.
- 메인·베타7의 기존 구르기 무적은 해당 베타8 옵션을 사용하지 않으므로 유지한다.
