# 베타 시즌 5 스펙

## 1. 개요

베타 시즌 5는 놀이공원을 배경으로 베타 후반부를 시작하는 시즌이다. 신규 캐릭터 **민트**, 블루의 신규 특수 공격 **바운스 샷**, 신규 모드 **SHOWDOWN+**를 중심으로 전투 콘텐츠를 확장한다.

| 항목 | 내용 |
|---|---|
| 시즌 ID | `beta5` |
| 전용 테마 | 놀이공원 |
| 테스트 주소 | `beta-season.html?test=beta5` |
| 전용 저장 키 | `colorsBetaSeason5Test` |
| 신규 캐릭터 | 민트 |
| 신규 특수 공격 | 블루 — 바운스 샷 |
| 신규 모드 | SHOWDOWN+ |
| 전용 음악 | `Clockwork Midway` |
| 정기 업데이트 시각 | 오후 6시 |

## 2. 시즌 범위와 분리 원칙

- 베타 시즌 5 콘텐츠는 `?test=beta5`에서만 활성화한다.
- 민트와 블루 특수 공격은 메인 게임 및 베타 시즌 4에 노출하지 않는다.
- 시즌 5 전적과 테스트 상태는 이전 시즌 데이터와 분리한다.
- 신규 캐릭터가 로스터에 추가되면 캐릭터별 시즌 전적 항목도 자동 생성한다.
- 베타 시즌 5 앱 전환안은 별도 문서 [`beta-season-5-app.md`](beta-season-5-app.md)에서 관리한다.

## 3. 놀이공원 테마

- 파스텔 하늘과 분홍·민트·노랑·보라색을 중심 색상으로 사용한다.
- 베타 광장 외곽에 관람차, 회전목마, 풍선 장식을 배치한다.
- 쇼다운은 분홍·민트 체크 바닥, 보라색 벽, 놀이공원 안내선과 조명을 사용한다.
- 장식물은 플레이어 이동, 투사체, 카메라 판정을 방해하지 않는다.
- 전용 음악 `assets/beta5-clockwork-midway.mp3`를 반복 재생한다.
- 음악은 첫 입력 후 재생하며 페이지가 숨겨지면 일시 정지한다.

## 4. 신규 캐릭터 — 민트

민트는 얼음 수치를 누적해 적을 빙결시키고 넓은 장판으로 이동을 방해하는 영웅 등급 컨트롤러다.

### 4.1 기본 능력치

| 항목 | 값 |
|---|---:|
| 최대 체력 | 6,600 |
| 이동속도 배율 | 1.05 |
| 공격 쿨다운 | 0.75초 |
| 재장전 | 1.15초 |
| 최대 탄약 | 3 |

### 4.2 일반 공격 — 아이스크림 탄

- 한 번 공격하면 아이스크림 탄환 3발을 120ms 간격으로 연속 발사한다.
- 탄환 1발 피해: 700
- 사거리: 10타일
- 탄속: 20
- 명중 1회당 얼음 수치 25를 누적한다.
- 얼음 수치 최대값은 100이다.
- 얼음 수치가 100이 되면 대상은 2초 동안 빙결한다.
- 빙결 중에는 이동, 일반 공격, 특수 공격을 사용할 수 없다.
- 빙결 발동 후 얼음 수치는 0으로 초기화한다.
- 대상 체력바 오른쪽에 현재 얼음 수치 또는 `빙결` 상태를 표시한다.
- 얼음 수치 UI와 피해량 팝업이 겹치지 않도록 별도 위치에 표시한다.

### 4.3 특수 공격 — 아이스크림 장판

- 민트가 바라보는 방향 10타일 지점에 장판을 생성한다.
- 반경: 9타일
- 지속시간: 10초
- 충전 요구량: 일반 공격 적중 8회
- 시간 경과만으로 특수 공격이 자동 충전되지 않는다.
- 장판 위 적은 1초마다 300 피해와 얼음 수치 5를 받는다.
- 빙결되지 않은 적은 장판 중심의 바깥 방향으로 미끄러진다.
- 미끄러짐 속도는 3.2로 시작해 장판 위에서 초당 0.6씩 증가한다.
- 장판 종료 직전 미끄러짐 속도는 최대 약 9.2다.
- 장판은 민트색 **불투명 원**으로 표시하며 10초 동안 투명해지지 않는다.

### 4.4 조작

- 좌클릭을 0.2초 이상 누르면 수동 에임을 활성화한다.
- 특수 공격은 충전 완료 후 특수 공격 버튼 또는 지정 키로 발동한다.

## 5. 블루 특수 공격 — 바운스 샷

- 블루가 탄환 8발을 70ms 간격으로 빠르게 발사한다.
- 전체 발사각은 18도 부채꼴이다.
- 탄환 1발 피해: 650
- 탄속: 28
- 최대 이동거리: 22타일
- 탄환은 벽에 최대 3번 반사한다.
- 탄환은 적을 관통하며 계속 이동한다.
- 동일 탄환은 같은 적에게 한 번만 피해를 준다.
- 재사용 대기시간: 10초
- 베타 시즌 5에서만 특수 공격 버튼과 게이지를 표시한다.

## 6. 신규 모드 — SHOWDOWN+

### 6.1 규칙

- 기본 쇼다운의 생존 규칙을 유지한다.
- 적 처치마다 +2점을 획득한다.
- 생존 순위와 처치 점수를 함께 고려해 적극적인 전투를 유도한다.

### 6.2 구현 상태

- 공개 로드맵과 공지에 모드 이름 및 핵심 규칙을 공개한다.
- 세부 승리 조건, 동점 처리, 트로피 계산, 전적 저장 방식은 구현 전에 확정한다.
- 현재 전용 테스트 페이지에는 SHOWDOWN+의 최종 점수 판정이 아직 구현되지 않은 계획 상태다.

## 7. 데이터와 UI

- 베타 시즌 5의 캐릭터 선택 화면에 민트를 추가한다.
- 민트와 블루를 선택하면 전용 특수 공격 설명 및 버튼을 표시한다.
- 민트의 얼음 수치는 대상 체력바 오른쪽에 표시한다.
- 시즌 5 전적은 이전 시즌과 분리하며 신규 캐릭터 항목을 자동 생성한다.
- 베타 시즌 4로 전환하면 민트 관련 UI와 저장 상태를 노출하지 않는다.
