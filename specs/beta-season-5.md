# 베타 시즌 5 스펙

## 1. 개요

베타 시즌 5는 놀이공원을 배경으로 베타 후반부를 시작하는 시즌이다. 신규 캐릭터 **민트**, 블루의 신규 특수 공격 **돌진**, 신규 모드 **SHOWDOWN+**를 중심으로 전투 콘텐츠를 확장한다. 이 문서는 `beta-season.html?test=beta5`와 실제 연결된 스크립트·설정값을 다시 대조한 최종 구현 기준이다.

| 항목 | 내용 |
|---|---|
| 시즌 ID | `beta5` |
| 전용 테마 | 놀이공원 |
| 테스트 주소 | `beta-season.html?test=beta5` |
| 전용 저장 키 | `colorsBetaSeason5Test` |
| 신규 캐릭터 | 민트 |
| 신규 특수 공격 | 블루 — 돌진(리코셰 대시) |
| 신규 모드 | SHOWDOWN+ |
| 전용 음악 | `assets/beta5-clockwork-midway.mp3` (`Clockwork Midway`) |
| 전용 로딩 이미지 | `assets/beta5-loading.png` |
| 시즌 스킨 | 솜사탕 핑크 |
| 정기 업데이트 시각 | 오후 6시 |

## 2. 시즌 범위와 분리 원칙

- 베타 시즌 5 콘텐츠는 `?test=beta5`에서만 활성화한다.
- 민트와 블루 특수 공격은 메인 게임 및 베타 시즌 4에 노출하지 않는다.
- 시즌 5 전적과 테스트 상태는 이전 시즌 데이터와 분리한다.
- 신규 캐릭터가 로스터에 추가되면 캐릭터별 시즌 전적 항목도 자동 생성한다.
- 베타 시즌 5 앱 전환안은 별도 문서 [`beta-season-5-app.md`](beta-season-5-app.md)에서 관리한다.

## 3. 놀이공원 테마

- 파스텔 하늘과 분홍·민트·노랑·보라색을 중심 색상으로 사용한다.
- 베타 광장 외곽에 관람차, 회전목마, 풍선 장식을 배치한다.
- 쇼다운은 분홍·민트 체크 바닥, 보라색 벽, 놀이공원 안내선과 조명을 사용한다.
- 장식물은 플레이어 이동, 투사체, 카메라 판정을 방해하지 않는다.
- 전용 음악 `assets/beta5-clockwork-midway.mp3`를 반복 재생한다.
- 음악은 첫 입력 후 재생하며 페이지가 숨겨지면 일시 정지한다.
- 시즌 5 진입 시 전용 놀이공원 로딩 이미지를 표시하고 최소 노출 시간이 지난 뒤 페이드아웃한다.

## 4. 신규 캐릭터 — 민트

민트는 얼음 수치를 누적해 적을 빙결시키고 넓은 장판으로 이동을 방해하는 영웅 등급 컨트롤러다.

### 4.1 기본 능력치

| 항목 | 값 |
|---|---:|
| 최대 체력 | 6,600 |
| 이동속도 배율 | 1.05 |
| 공격 쿨다운 | 0.75초 |
| 재장전 | 1.15초 |
| 최대 탄약 | 3 |

### 4.2 일반 공격 — 아이스크림 탄

- 한 번 공격하면 아이스크림 탄환 3발을 120ms 간격으로 연속 발사한다.
- 탄환 1발 피해: 700
- 사거리: 10타일
- 탄속: 20
- 명중 1회당 얼음 수치 25를 누적한다.
- 얼음 수치 최대값은 100이다.
- 얼음 수치가 100이 되면 대상은 2초 동안 빙결한다.
- 빙결 중에는 이동, 일반 공격, 특수 공격을 사용할 수 없다.
- 빙결 발동 후 얼음 수치는 0으로 초기화한다.
- 대상 체력바 오른쪽에 현재 얼음 수치 또는 `빙결` 상태를 표시한다.
- 얼음 수치 UI와 피해량 팝업이 겹치지 않도록 별도 위치에 표시한다.

### 4.3 특수 공격 — 아이스크림 장판

- 민트가 바라보는 방향 10타일 지점에 장판을 생성한다.
- 반경: 9타일
- 지속시간: 10초
- 충전 요구량: 일반 공격 적중 8회
- 시간 경과만으로 특수 공격이 자동 충전되지 않는다.
- 장판 위 적은 1초마다 300 피해와 얼음 수치 5를 받는다.
- 빙결되지 않은 적은 장판 중심의 바깥 방향으로 미끄러진다.
- 미끄러짐 속도는 3.2로 시작해 장판 위에서 초당 0.6씩 증가한다.
- 장판 종료 직전 미끄러짐 속도는 최대 약 9.2다.
- 장판은 민트색 **불투명 원**으로 표시하며 10초 동안 투명해지지 않는다.

### 4.4 조작

- 좌클릭을 0.2초 이상 누르면 수동 에임을 활성화한다.
- 특수 공격은 충전 완료 후 특수 공격 버튼 또는 지정 키로 발동한다.

## 5. 블루 특수 공격 — 돌진

초기 기획의 바운스 샷은 폐기되었으며, 실제 시즌 5 구현은 블루 본인이 구르며 이동하는 **리코셰 대시**다.

- 일반 공격 적중으로 충전하며 요구 충전량은 4회다.
- 발동 시 블루가 바라보는 방향으로 빠르게 굴러간다.
- 이동속도: 24
- 지속시간: 1.15초
- 경로에 있는 적에게 1,600 피해와 넉백을 준다.
- 적중 반경: 1.2타일
- 같은 돌진 중 동일한 적은 한 번만 피해를 받는다.
- 벽에 닿으면 진행 방향을 반사하며, 반사 횟수에는 제한이 없다.
- 베타 시즌 5에서만 특수 공격 버튼과 충전 게이지를 표시한다.

## 6. 신규 모드 — SHOWDOWN+

SHOWDOWN+는 베타 시즌 5의 쇼다운을 **대체**한다. `?test=beta5`에서 쇼다운에 진입하면 항상 SHOWDOWN+가 실행되며, 기존 쇼다운 규칙은 베타 시즌 4 이하에만 남는다.

### 6.1 규칙

- 기본 쇼다운의 생존 규칙을 유지한다. AI 9명과 플레이어 1명, 총 10명이 참가하고 사망 시 부활하지 않는다.
- 최종 등수는 **생존 순위 그대로** 정한다. 처치 점수는 등수를 바꾸지 않는다.
- 승패 판정도 기존과 같이 **4위 이내면 승리**로 처리한다. 처치 수는 승패에 영향을 주지 않는다.
- 적 처치 1회마다 트로피 **+2**를 추가로 획득한다.
- 처치 점수에는 **상한이 없다**. 최대 9처치까지 그대로 가산한다.
- 플레이어가 마지막 타격을 준 처치만 인정한다. AI끼리의 처치는 점수로 세지 않는다.

### 6.2 최종 트로피 계산

```
트로피 변화량 = (12 - 등수 × 2) + (처치 수 × 2) + 연승 보너스
```

- 등수 점수는 1위 +10, 6위 0, 10위 -8이다.
- 연승 보너스는 기존과 같이 `min(연승 - 1, 4)`이며 4위 이내 진입 시에만 연승이 누적된다.
- 하위 등수에서도 처치 점수로 손실을 상쇄할 수 있다. 예: 10위 3처치 = -8 + 6 = -2.
- 캐릭터 트로피 총합은 0 미만으로 내려가지 않는다.
- 한 판 최대 획득량은 1위 · 9처치 · 5연승 기준 +32다.

### 6.3 동점 처리

최종 등수를 생존 순위로만 정하므로 **동점은 발생하지 않는다**. 별도의 타이브레이크 규칙을 두지 않는다.

### 6.4 전적 저장

| 필드 | 범위 | 내용 |
|---|---|---|
| `characterShowdownKills` | 캐릭터별 | SHOWDOWN+ 누적 처치 수 |
| `bestShowdownKills` | 계정 전체 | 한 판 최고 처치 수 |

- 두 필드 모두 베타 시즌 5 전용 저장 키 `colorsBetaSeason5Test`에 기록한다.
- 기존 저장 데이터에 필드가 없으면 0으로 초기화한다.
- 캐릭터 카드의 트로피 배지 툴팁에 누적 처치 수를 함께 표시한다.

### 6.5 HUD

- 모드 제목을 `SHOWDOWN+`로 표시한다.
- 생존 인원 옆에 현재 처치 수를 실시간으로 표시한다.
- 매치 종료 토스트에 `등수 · 승패 · 처치 수 · 트로피 변화량`을 함께 표시한다.

## 7. 데이터와 UI

- 베타 시즌 5의 캐릭터 선택 화면에 민트를 추가한다.
- 민트와 블루를 선택하면 전용 특수 공격 설명 및 버튼을 표시한다.
- 민트의 얼음 수치는 대상 체력바 오른쪽에 표시한다.
- 시즌 5 전적은 이전 시즌과 분리하며 신규 캐릭터 항목을 자동 생성한다.
- 베타 시즌 4로 전환하면 민트 관련 UI와 저장 상태를 노출하지 않는다.

### 7.1 일일 보상

- 메인과 같은 별 회전형 공개 연출을 사용하되, 등급을 먼저 결정한 다음 회전 연출을 재생한다.
- 업그레이드 기회는 4회다.
- 일반 등급의 개별 업그레이드 확률은 25%, 희귀 이상은 12%다.
- `남은 기회 한 번에 사용`은 각 판정에 3%p 보너스를 적용한다.
- 일반 등급의 마지막 기회는 업그레이드를 보장한다.
- 단계 상승 가중치는 1단계부터 10단계까지 `40/20/12/8/6/5/4/2.5/1.5/1`이며, 10단계 확률은 1%다.
- `?` 버튼을 누르면 업그레이드 및 단계 상승 확률표를 표시한다.
- 7단계 이상은 강화 이펙트를 사용하고 10단계는 최대 이펙트를 사용한다.

### 7.2 모델과 에셋 쇼룸

- 에셋 쇼룸에서 전투용 GLB/FBX 모델을 직접 회전·확대하고 애니메이션을 재생할 수 있다.
- 민트는 걷기 시작·반복·종료 FBX 모션을 사용하며 전투 공격 동작도 재생한다.
- 시즌 스킨 **솜사탕 핑크**는 전용 FBX 걷기 모션을 사용한다.
- 모델 애니메이션 중 T 포즈가 걷기 동작과 겹치거나 종료 후 나타나지 않도록 상태 전환을 유지한다.

### 7.3 컬러스 스토리북

- 베타 메뉴에 독립적인 `컬러스 스토리북` 버튼을 제공한다.
- 본문은 `beta-storybook-content.html`에서 불러온다.
- 긴 문서를 탐색할 수 있도록 시대별·장별 접이식 목차와 장 바로가기를 제공한다.
