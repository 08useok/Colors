## 2026년 10월 20일 — 살몬·라즈베리 전투 계획안 정리

- 살몬은 회수 범위에 찌가 있고 탄약이 5발 미만이면 발사 대신 가장 가까운 찌 1개를 회수합니다. 회수에는 일반 공격 쿨다운을 적용하지 않으며 궁극기 포인트도 지급하지 않습니다. 탄약 5발이면 회수 대신 기존 쿨다운에 따라 일반 공격을 발사하는 기획을 확정했습니다. 게임에는 아직 적용하지 않았습니다.
- 살몬 궁극기의 **동시 설치 상한 없음**을 확정했습니다. 재사용 시 기존 장치를 유지하며 새로운 원형 장치 세트를 추가 설치합니다. 파괴 시 자동 복구 없음·설치자 사망 시 유지·라운드 종료 및 모드 전환 시 전체 제거 규칙은 유지합니다. 기획 문서 변경입니다.
- 살몬 궁극기는 장치 파괴 지점을 탈출구로 만들고 자동 복구하지 않으며, 설치자 사망 시 유지·라운드 종료 및 모드 전환 시 전체 제거하는 기획을 확정했습니다.
- 살몬 궁극기는 같은 적 재포획을 전체 장치 공유 2초 간격으로 제한하고, 동시 장치 접촉 피해·띄우기는 1회만 적용하며 공중 대상 재포획을 금지하는 기획을 확정했습니다. 감속 삭제안은 채택하지 않아 기존 30%·1초 제안을 유지합니다. 기획 문서 변경입니다.
- 살몬 궁극기 장치 접촉 시 **포획 + 0.85초 띄우기**를 적용하는 기획을 확정했습니다. 접촉 피해 700~1,050은 유지하며 일반 공격의 탄약 +1발·궁 충전 +4포인트 보상은 지급하지 않습니다. 게임에는 아직 적용하지 않았습니다.
- 살몬 궁극기 장치의 접촉 피해 계획을 350에서 **700~1,050(+100~200%)**으로 상향했습니다. 범위 안의 최종 고정 수치는 미정이며 게임에는 아직 적용하지 않았습니다.
- 살몬 포획을 착지 범위 내 최근접 적 1명으로 확정했습니다. 포획 대상은 총 1,800 피해·0.85초 띄우기, 주변 적은 600 피해만 받습니다. 성공 시 탄약 1발·궁극기 4포인트를 얻으며 주변 범위 적중만으로는 포획 보상을 주지 않습니다. 기획 문서 변경입니다.
- 살몬의 낚시찌 회수 보상을 **찌 1개당 탄약 1발**로 확정했습니다. 최대 탄약은 5발이며 기획 문서에만 반영했습니다.
- 살몬은 근처 1~4타일의 빗나간 낚시찌를 일반 공격 버튼으로 회수하는 기획을 확정했습니다. 탄약 0발에서도 회수 입력은 가능하며 자동 재장전은 추가하지 않습니다. 게임에는 아직 구현하지 않았습니다.
- [살몬](characters/salmon.md)·[라즈베리](characters/raspberry.md)의 제공 계획안을 캐릭터별 문서로 정리했습니다. 확정·제안·미정 규칙을 구분합니다.
- 게임 구현·능력치 적용·시뮬레이션은 진행하지 않았습니다. 출시 시즌과 레벨 기준도 임의로 정하지 않았습니다.

- 캐릭터 FBX/GLB와 해당 텍스처의 실제 로딩 진행을 추적하는 화면을 추가했습니다. 모든 요청 완료와 모델 부착 후 두 프레임을 확인한 뒤 화면을 엽니다.

## v1.7.0.2 — 공격·조준 표시 오류 수정

2026년 10월 13일 · 메인 및 베타

### 시안

- 일반 공격의 알약 6발이 부채꼴로 퍼지던 문제를 수정했습니다. 이제 0.75타일 간격으로 평행하게 날아갑니다.

- 시즌 7 알약당 피해량은 700으로 유지됩니다.

### 조준 표시

- 메인에서 골드·민트·애저의 일반 공격 조준 표시가 나오지 않던 문제를 수정했습니다. 애저는 파도의 공격 폭도 표시합니다.
- 메인 아이보리의 조준 표시와 실제 투척 위치가 달랐던 문제를 수정했습니다. 조준한 거리에 착탄 범위가 표시됩니다.
- 메인과 베타에서 궁극기 버튼 또는 Q/Space를 누르고 있는 동안 범위를 확인하고, 놓으면 사용하도록 변경했습니다.
- 방향성 궁극기는 경로와 폭, 오렌지는 부채꼴 범위, 아이보리는 5개 착탄 범위, 투척형 궁극기는 착탄 위치를 표시합니다. 자신을 중심으로 사용하는 궁극기는 적용 범위를 표시합니다.
- 조준을 취소하거나 게임 창에서 포커스가 벗어나면 조준 표시가 해제됩니다.
