# v1.7.0.2 — 공격·궁극기 조준 표시 수정

## 변경

- 시안: 메인과 베타의 공유 전투, 베타 훈련장 공격 모두 알약 6발을 0.75타일 간격으로 평행 발사한다. 시즌 7 알약당 피해 700은 유지한다. 베타의 일반 공격 표시도 평행 탄막으로 바꾼다.
- 메인 골드·민트·애저: 일반 공격 조준 표시를 추가한다. 애저는 실제 파도 폭을 표시한다.
- 메인 아이보리: 포인터까지의 거리를 일반 공격 사거리로 제한해 투척 위치와 착탄 원을 표시한다. 실제 공격도 같은 위치로 날아간다. 봇은 플레이어의 조준 위치를 사용하지 않는다.
- 메인·베타 궁극기: 버튼 또는 Q/Space를 누르는 동안 범위를 표시하고 놓으면 사용한다. 방향성 궁극기는 경로/폭, 오렌지는 부채꼴, 아이보리는 실제 5개 착탄 장판, 투척은 착탄 위치, 자기 중심 기술은 영향 범위를 표시한다. 취소와 창 포커스 해제 시 조준을 해제한다.
- 라벤더는 시즌 8 베타에서만 플레이한다. 메인 시즌 7의 15종 구성은 유지한다.
- 네트워크 공격·궁극기 메시지에 포인터 위치를 포함해 원격 아이보리 투척도 같은 거리 입력을 받도록 연결한다.

## 검증

- `node tools/test-aim-guides.mjs`: 16종 궁극기 범위의 유효한 수치, 신규 일반 공격 표시, 시안 발사 각도 3개에서 평행 속도·간격, 거리 2/5/8타일의 같은 중앙 적중 피해 1,400, 아이보리 수동 착탄 거리.
- `node tools/test-aim-guides-browser.mjs`: 실제 로컬 페이지에서 메인 15종 일반·궁극기 표시, 시즌 8 베타 16종 궁극기 표시, Q 누름/해제와 조준 숨김, 페이지 실행 오류 없음. 캐릭터 모델과 계정은 검사 중 제어한 상태다.
- `npm run check`, `npm run check:main7`, `npm run check:beta6`.
- [브라우저 검사 기록](aim-guide-browser-verification.json), [아이보리 궁극기 범위 화면](aim-guide-ivory.png).
