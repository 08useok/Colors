## 할 일 (2026-11-01 등록·처리)

10개 모두 처리했다. 결정 항목은 2026-11-01 사용자 결정을 따른다. 검사·측정 파일은 `tools/`에 있다. 캐릭터별 기획서(아이보리·민트·샤트·핑크 등)는 미커밋 수정이 있어 이 문서에만 기록했다.

### 우선 처리

- [x] **살몬의 0발 탄약 문제 해결** — 원인: 살몬이 쓰러지면 찌가 사라지는데, 메인 부활(쇼다운 외 이벤트·훈련장·테이크다운)과 핑크 앙코르 부활이 탄약을 채우지 않아 영구 0발이 됐다. 수정: 메인 부활 3경로에서 탄약 가득, 엔진 앙코르 부활 시 살몬 탄약 가득. 검사 `test-salmon-ammo-return.mjs`.
- [x] **핑크 광역 부활의 범위·조건 결정** — 결정: 효과 중 쓰러진 아군은 **쓰러진 자리에서 3초 뒤** 체력 40%로 부활(기획서대로, 기존 코드는 즉시 부활이었음). 대상은 **사용 순간 반경 8타일 안의 아군, 자신 제외**를 유지. 예약된 부활은 12초 효과가 끝나도 유지, KNOCKOUT에서는 불가. 엔진 반영, `test-knockout.mjs`에 3초 지연 검증 추가.
- [x] **라즈 원형 속박의 세부 판정 결정** — 결정: 캐릭터 **중심점**이 반지름 3.5 원 안이면 대상(경계 포함). 발동 순간 공중 대상은 최초 효과 제외, 돌진 중 대상은 돌진을 끝내고 속박. [라즈베리 기획서](characters/raspberry.md)에 기록. 캐릭터는 아직 미구현.
- [x] **샤트 확률형 공격의 공정성 검토** — `analyze-chartreuse-plague.mjs`, [결과 JSON](beta9-chartreuse-plague.json). 즉사탄이 평균 점수율을 47.8% → 54.9%로 올리며, 주로 불리한 상대(크림슨 0→11%, 퍼플 3→11%, 핑크 10→24%, 골드 31→52%)에서 운에 의한 역전을 만든다. 궁극기 중 확률 하향(33→15%)은 1:1에서 효과 없음. 제안: **체력 50% 이하 대상만 즉사, 그 이상은 강화탄 피해(2,640)** → 평균 50.9%, 지정 상성 유지. 엔진에 설정값(`chartreusePlagueChance`·`chartreuseFocusPlagueChance`·`chartreusePlagueExecuteRatio`)만 추가했고 기본값은 기존과 같다. **결정(2026-11-01): 현재 유지.** 확률형 정체성을 그대로 두며, 조정이 필요하면 위 설정값으로 바로 바꿀 수 있다.

### 다음 단계

- [x] **아이보 X자형 궁극기 판정 구체화** — 측정(`probe-ivory-ultimate.mjs`): 중심 1 + 대각선 4개(중심에서 3.5타일), 착탄·장판 반경 5타일. 착탄은 **겹치면 모두 적용**되어 중심 대상은 0.2초 안에 3,000×5 = 15,000(전 캐릭터 즉사), 축 3.5타일 9,000, 축 6타일 6,000, 8타일 이상 0. 장판은 겹쳐도 초당 1회(3,250). 반경 5가 간격 3.5보다 커서 X자 모양이 판정에 드러나지 않는다. **결정·적용(2026-11-01): 착탄 피해는 한 번의 궁에서 대상당 1회.** 중심 15,000 → 3,000, 장판(초당 3,250, 비중첩)과 범위·모양은 유지. 궁 설명에 문구 추가, 검사 `test-ivory-ultimate-impacts.mjs`. 전체 32,640경기 재실행 결과 지정 17연결 전승·평균 점수율 변화 없음(1:1에서는 궁 사용이 드묾).
- [x] **민트 빙판 장판의 이동 판정 구체화** — 측정(`probe-mint-field.mjs`): 실제 동작은 미끄러짐이 아니라 **중심에서 바깥으로 계속 미는 힘**(초당 3.2 + 0.6×경과초 타일). 얼지 않은 적만 밀리고, 벽은 넘지 않는다. 가만히 있는 적은 중심에서 3.1초, 3타일에서 2.4초, 7타일에서 1.4초 만에 가장자리로 밀려나 피해 1~3회(563씩)만 받는다. 벽에 붙으면 10초 내내 5,630 피해·얼음 50. 장판만으로는 빙결(100)에 도달하지 않는다. **결정(2026-11-01): 밀어내기 유지.** 구역을 비우는 기술로 확정하고, 한·영 설명을 실제 동작(바깥으로 밀어냄, 초당 3.2타일 + 매초 0.6 가속, 얼은 적 제외, 벽에서 멈춤)으로 고쳤다. 영어 설명의 "300 damage" 오류도 563으로 바로잡았다.
- [x] **블루 넉백·벽 반사 상호작용 테스트** — `test-blue-wall-interactions.mjs`: 벽·맵 경계에 막히면 **180° 되돌아간다**(입사각 반사 아님). 벽 안으로 들어가지 않고, 같은 적은 한 번 구를 때 1회만 맞으며, 넉백은 벽에서 멈춘다.
- [x] **크탈 분열탄·구속 궁극기 판정 검증** — 기존 검사 4종 통과 + `test-crystal-edge-cases.mjs`: 근접 명중 시 단계별 1회(최대 3,500), 레드 보호막을 무시하는 고정 28,000, 28,000보다 체력이 많으면 생존 후 해제, 분석 중 대상이나 크리스탈이 쓰러지면 즉시 해제. 분석 중 블루는 행동 불가라 구르기 보호막이 켜지지 않는다.
