# 캐릭터 선택 시스템

## UI 흐름

1. 계정 진입 후 로비에서 캐릭터 선택 화면을 연다.
2. 보유 캐릭터를 선택해 선택 상태와 미리보기를 갱신한다.
3. 선택한 캐릭터로 지원되는 게임 모드 또는 훈련장에 진입한다.
4. 퇴장 후 로비의 선택 상태를 복원한다.

## 정의와 보유 상태

- 능력치와 공격 설명: [캐릭터별 스펙](04-characters.md).
- 등급·크레딧 구매: [캐릭터 등급·구매](character-rarity-shop.md).
- 메인 로스터: [src/main.js](../src/main.js)의 `ROSTER`.
- 베타 테스트 로스터: [src/beta-season.js](../src/beta-season.js)의 `CHARACTERS`.
- 미보유 캐릭터는 잠금과 가격을 표시하고 선택을 차단한다.
- 스탯 표를 이 문서에 복제하지 않는다. 캐릭터 추가 시 로스터와 캐릭터별 문서를 갱신한다.

## AI 봇

- 봇의 캐릭터 배정은 플레이어의 보유 목록과 분리한다.
- 봇 수와 외형 선택은 모드별 생성 코드가 기준이며, 9종 캐릭터 목록으로 고정하지 않는다.
- 선택한 캐릭터의 공격 타입에 맞는 전투 로직을 사용한다.

## 검증 기준

- 보유한 캐릭터를 선택하고 해당 캐릭터의 스탯으로 플레이할 수 있다.
- 미보유 캐릭터의 잠금과 구매 후 해제가 동작한다.
- 캐릭터 변경 시 이전 모델·스킨이 남지 않는다.
- [훈련장](training-arena.md)에도 현재 선택이 적용된다.
- 퇴장 후 로비의 선택 상태가 복원된다.
