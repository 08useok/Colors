# 메인 꼬리잡기 설계 변경

## 변경한 연결

**크리스탈 → 크림슨 → 퍼플**로 지정 상성의 설계 방향을 바꿉니다. 기존 **크림슨 → 크리스탈** 승리 목표는 폐기합니다. 메인 15종 기준이며 베타 시즌의 16종 순환과 전투 수치는 바꾸지 않습니다.

| 공격자 | 새 목표 상대 | 현재 승률 | 목표 충족 |
|---|---|---:|---|
| 크리스탈 | 크림슨 | **100.0%** | **100%** |
| 크림슨 | 퍼플 | 100.0% | **100%** |

크리스탈의 수정 분석은 적중 즉시 처치하지 않습니다. 분석 중 두 캐릭터의 이동·공격을 막고, 대상이 생존하면 8초 뒤 처형합니다. 크림슨의 지속 공격은 분석 중 중단되므로 크림슨에게 크리스탈 100% 승리를 요구하던 방향을 뒤집었습니다. 설계 변경 당시에는 73.8%였으며, 후속 중첩·피해 조정과 첫 수정탄 추적으로 600회 중 600승을 확인했습니다. [최신 검증](crystal-counter-choice.md)을 참고하세요.

## 전체 순환은 아직 미확정

아래 전체 순환 후보와 승률은 최초 설계 시점의 비교 기록입니다. 최신 크리스탈 승률과 전체 미달 상태는 위 최신 검증 문서에서 구분합니다.

시안의 최고 상대별 승률이 24.4%라서 순서 변경만으로 전원 100% 승리 대상을 지정할 수 없습니다. 새 연결을 포함하는 완전한 순환의 탐색 결과도 가장 약한 연결이 24.4%입니다. 아래는 비교 후보이며 확정된 꼬리잡기 순서가 아닙니다.

레드 → 블루 → 오렌지 → 민트 → 시안 → 그린 → 애저 → 골드 → 핑크 → 아이보리 → 크리스탈 → 크림슨 → 퍼플 → 샤르트뢰즈 → 옐로우 → 레드

| 캐릭터 | 후보 승리 상대 | 현재 승률 |
|---|---|---:|
| 레드 | 블루 | **100.0%** |
| 블루 | 오렌지 | **100.0%** |
| 오렌지 | 민트 | **100.0%** |
| 민트 | 시안 | **100.0%** |
| 시안 | 그린 | 24.4% |
| 그린 | 애저 | 89.5% |
| 애저 | 골드 | **100.0%** |
| 골드 | 핑크 | 29.0% |
| 핑크 | 아이보리 | **100.0%** |
| 아이보리 | 크리스탈 | 65.3% |
| 크리스탈 | 크림슨 | 73.8% |
| 크림슨 | 퍼플 | **100.0%** |
| 퍼플 | 샤르트뢰즈 | **100.0%** |
| 샤르트뢰즈 | 옐로우 | **100.0%** |
| 옐로우 | 레드 | 66.2% |

현재 승률이 50% 아래인 연결까지 있으므로 이 후보를 완성된 상성표로 적용하지 않습니다. 능력치 조정 또는 일부 캐릭터의 순환 제외 없이는 전체 목표를 달성할 수 없습니다.

## 검증 근거

- 메인 15종, 6레벨, 궁극기 포함(충전 0 시작), 대진당 600회 결과를 재사용했습니다. 이번 작업에서 수치나 전투 결과를 바꾸지 않았습니다.
- 한 캐릭터가 한 번씩 들어가는 순환 전체를 동적 계획법으로 탐색했습니다. 크리스탈→크림슨은 필수이고, 크림슨→크리스탈은 금지했습니다.
- 승률은 지정한 시뮬레이션 조건의 관측값이며, 실제 플레이 전체의 보장값이 아닙니다.
