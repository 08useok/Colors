# 베타 시즌 7 밸런스 패치

시즌 6 시뮬레이션 순위의 상위 5명을 약하게 너프하고 하위 4명을 약하게 버프한다.
**시즌 7 전용**이다. 시즌 6·8과 본 게임은 바뀌지 않는다. 크리스탈은 시뮬레이션 자료가 없어 건드리지 않는다.
구현: `src/config/beta7-balance.js` (`applyBeta6Balance` 위에 덧씌움).

## 너프

| 캐릭터 | 변경 |
|---|---|
| 오렌지 | 체력 4400 → 4000, 파편 피해 1300 → 1170 |
| 블루 | 구슬 피해 1200 → 1080, 사거리 17.5 → 16 |
| 레드 | 체력 9800 → 9000, 공격 피해 2400 → 2160 |
| 퍼플 | 독 피해 초당 912 → 820, 독병 3240 → 2920 |
| 그린 | 체력 8400 → 7600, 부메랑 1900 → 1710 |

## 버프

| 캐릭터 | 변경 |
|---|---|
| 골드 | 체력 7500 → 8200, 1/2/3단계 피해 900/450/225 → 990/495/250 |
| 아이보리 | 체력 6000 → 6600, 아이스크림 피해 2000 → 2200 |
| 핑크 | 체력 9000 → 9900, 치유 원 피해 2000 → 2200 |
| 샤르트뢰즈 | 체력 6200 → 6800, 탄 피해 1200/2400 → 1320/2640 |

승패 목표는 두지 않았다. 시즌 종료 후 시뮬레이션으로 변화 폭을 확인한다.
