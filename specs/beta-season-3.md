# 베타 시즌 3 스펙

## 1. 개요

베타 시즌 3은 아이스크림 가게 콘셉트의 플레이어블 캐릭터 **아이보리**를 정식 추가하는 시즌이다.
아이보리는 2026-08-03(`255b38d`, `18e710e`)에 `src/beta-season.js`/`src/config/beta-characters.js`에
전투 프로토타입까지 이미 만들어져 있고, 베타 테스트 페이지 캐릭터 로스터에도 등록되어 실제로
선택·플레이 가능한 상태다. 이번 시즌의 과제는 이 프로토타입을 다듬고 **본 게임(`index.html`/`main.js`)에도
동일하게 연결**하는 것이다.

| 항목 | 내용 |
|---|---|
| 시즌 ID | `beta3` |
| 신규 플레이어블 캐릭터 | 아이보리 (아이스크림 가게 직원) |
| 등급 | 영웅 (900 크레딧) |
| 상태 | 베타 페이지 프로토타입 완료, 본 게임 미연결 |

## 2. 목표

- 이미 베타 페이지에 프로토타입된 아이보리를 정식 콘텐츠로 다듬는다.
- 밸런스·연출을 확정하고 스킨/상점 노출까지 연결한다.
- **본 게임에도 동일하게 이식한다** — 이 프로젝트에서 반복돼온 "베타 페이지에만 구현되고 본 게임엔
  누락" 문제를 이번엔 처음부터 요구사항에 못 박아 재발을 막는다.

## 3. 플레이어블 캐릭터: 아이보리

### 콘셉트

> "발랄한 아이스크림 가게 직원입니다. 잘 녹지 않는 아이스크림으로 전장을 장악합니다."

- 아이스크림 가게에서 일하는 발랄한 직원 콘셉트의 전투 캐릭터
- 정돈된 동작으로 아이스크림을 던지고 장판을 까는 지역 통제형 캐릭터
- 색상: `0xfffff0` (아이보리 화이트)

### 외형 (확정 필요)

- 아이보리색 계열의 둥근 몸체
- 아이스크림 가게 직원 유니폼(앞치마 또는 모자 등 디테일은 구현 단계에서 확정)
- 무기 프롭: 아이스크림 스쿱 — `createIvoryScoopMesh()`로 이미 구현됨

### 등급/가격

- 등급: **영웅 (900 크레딧)**
- `src/beta-season.js`의 `CHARACTERS` 배열에는 내부 키가 `rarity: "legendary"`로 되어 있는데,
  이 파일의 `rarityName()` 매핑에서 `legendary`가 한국어로 "영웅"으로 표시된다. 즉 **코드 수정 없이
  이미 요청한 등급/가격과 일치**한다.
- 본 게임 `main.js`의 `CHARACTER_RARITY`에서는 hero=900 크레딧 / legendary=1200 크레딧으로
  값 자체가 분리되어 있으므로, 본 게임에 이식할 때는 반드시 `hero`로 등록해야 900 크레딧이 유지된다
  (`legendary`로 넣으면 1200 크레딧이 되어버림).

### 무기·전투 (이미 구현된 값, `src/config/beta-characters.js:174-192`)

| 항목 | 값 |
|---|---|
| 체력 | 6,200 |
| 이동속도 배율 | 1.0 |
| 공격 쿨다운 | 0.7s |
| 재장전 | 0.8s |
| 최대 탄약 | 3 |

**일반 공격 — 안 녹는 아이스크림**
최대 10타일 거리로 아이스크림을 던져 적중 시 1,100 즉발 피해를 주고, 착탄 지점에 4초 동안
장판을 생성한다. 장판은 1초마다 1,100 피해를 주며 장판 피해는 중첩되지 않는다.

**궁극기 — 단체 주문 (`groupOrder`)**
최대 20타일 거리의 지정 위치에 아이스크림 5개를 중앙 1개와 상하좌우 4개 패턴으로 투척한다
(`patternRadius: 3.5`). 각 아이스크림은 착탄 시 동일한 장판을 생성한다.

- 궁극기 충전 요구량: 12
- 조작: 일반 공격은 좌클릭, 궁극기는 궁극기 버튼 또는 Q 키

## 4. 요구사항

### 4.1 베타 페이지 마감

- 기존 프로토타입의 조준 인디케이터·궁극기 게이지·투척 로직을 유지하며 버그를 정리한다.
- 캐릭터 선택 카드에 이름·등급(영웅)·설명이 정확히 표시되는지 확인한다.

### 4.2 본 게임 연결 (신규 요구사항)

- `src/config/characters.js`의 `CHARACTERS`에 아이보리를 `hero` 등급·900 크레딧으로 등록한다.
- `index.html`의 캐릭터 선택 카드(`.char-btn`)와 로비 미리보기에 아이보리를 추가한다.
- 몸체 모델 전략(절차생성 / 시안 리그 공유 / 전용 GLB)을 확정하고 `createStickman`에 연결한다.
  이번 세션에서 시안 리그 공유 캐릭터들의 텍스처 리컬러·애니메이션 강제재생 버그를 여러 건 고쳤으니,
  기존 방식을 그대로 복사하기 전에 어느 쪽으로 갈지 먼저 정한다.
- 상점(캐릭터 구매 탭)에 아이보리를 노출한다.

### 4.3 스킨/상점 연결

- 아이보리 전용 스킨은 `src/config/skins.js`에 등록하고 상점 카드에 등급 배지와 함께 표시한다.
- 해금/구매는 기존 크레딧 시스템을 그대로 사용한다.
- 구매 전에는 가격과 보유 크레딧을 표시하고, 구매 후에는 잔액과 보유 상태를 즉시 갱신한다.

### 4.4 기존 기능 호환

- 베타 시즌 1·2 캐릭터와 스킨 데이터는 유지한다.
- 기존 `beta-season.html`의 전투 테스트와 캐릭터 선택 기능을 깨뜨리지 않는다.
- 계정 저장 형식과 기존 크레딧을 변경하지 않는다.

## 5. 제외 범위

- 아이스크림 콘셉트 자체의 재변경(다른 테마로 바꾸는 것)
- 신규 결제 수단
- 서버 기반 거래 시스템
- 시즌 3 전체 맵의 최종 아트 제작

## 6. Acceptance Criteria

- [ ] 베타 페이지·본 게임 양쪽에서 아이보리를 플레이어블 캐릭터로 선택할 수 있다.
- [ ] 양쪽 캐릭터 선택 화면에 아이보리 이름·등급(영웅)·가격(900)이 표시된다.
- [ ] 일반 공격 `안 녹는 아이스크림`이 최대 10타일 거리에서 적중 시 1,100 피해를 준다.
- [ ] 일반 공격 착탄 지점에 4초 장판이 생성되고 1초마다 1,100 피해를 준다(중첩 없음).
- [ ] 궁극기 `단체 주문`이 최대 20타일 위치에 중앙·상하좌우 5개 아이스크림을 투척한다.
- [ ] 궁극기는 게이지 12 충전 후 Q 또는 궁극기 버튼으로 사용할 수 있다.
- [ ] 본 게임 상점에서 아이보리 구매·잔액 갱신이 정상 동작한다.
- [ ] 아이보리 스킨이 있다면 상점에 등급 배지와 함께 표시된다.
- [ ] 크레딧 부족 시 구매가 차단되고 안내가 표시된다.
- [ ] 페이지 로드와 전투 중 콘솔 오류가 발생하지 않는다.

## 7. 검증 방법

1. 베타 페이지(`beta-season.html`)와 본 게임(`index.html`) 양쪽에서 아이보리를 선택한다.
2. 일반 공격 착탄 피해·장판 지속 피해, 궁극기 5연발 패턴을 확인한다.
3. 본 게임 상점에서 구매 가능·구매 성공·크레딧 부족 상태를 각각 확인한다.
4. 브라우저 콘솔 오류 로그를 확인한다.
