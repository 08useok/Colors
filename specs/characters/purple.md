# Purple

메인 캐릭터. 독침과 벽을 넘는 독병을 번갈아 쓰는 투척형 제어 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 6,000 / 1.0 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.45초 / 탄약 1개당 1.1초 |

## 일반 공격 — 독침과 독병

공격할 때마다 다음 두 방식이 번갈아 나온다.

1. **독침**: 전방 24도 부채꼴로 3발을 발사한다. 독침당 피해 700, 사거리 14타일. 적중 시 4초 동안 초당 760의 독 피해.
2. **독병**: 사거리 11타일의 포물선 투척. 벽 상단보다 높게 출발하며 착지 후 반경 4타일에 2,700 광역 피해.

## 특수/궁극기

- 메인 기준 별도 궁극기는 없다.

## 독·검증 기준

- 독침 한 발만 명중해도 독을 부여한다. 여러 발이 적중해도 독은 중첩하지 않고 지속시간을 갱신한다.
- 독침의 직접 피해·지속 피해와 독병의 착지 범위 피해를 각각 확인한다.
- 캐릭터 선택 잠금, 봇 배정과 기존 통계 보존을 확인한다.

베타 궁극기 `독성 대도약`은 시즌 7에서 선행 도입되고 시즌 8에도 유지된다. 기능과 수치는 [시즌 7 스펙](../beta-season-7.md#퍼플-신규-궁극기--독성-대도약)을 참조한다.


## 베타 시즌 8 궁극기 — 방사형 가시

- 이륙과 착지 때 각각 **16발**, 한 번의 도약에서 총 **32발**을 360도로 발사한다. 방향 간격은 22.5도다.
- 가시는 초당 14타일로 이동하며 최대 이동 거리 3.5타일, 충돌 반지름 0.14타일이다.
- 기존 원형 즉시 피해를 가시 명중 피해로 대체한다. 베타 시즌 8의 피해량 6,250을 유지하며, 같은 적은 이륙 발사에서 한 번·착지 발사에서 한 번까지만 피해를 받는다. 겹치는 가시는 추가 피해·궁 충전을 주지 않는다.
- 명중 대상마다 발사 단계당 궁극기 1칸을 재충전한다. 아군은 피해를 받지 않고 가시는 벽에 막히며 관통하지 않는다.
- 기존 궁극기처럼 별도 독 지속 피해는 추가하지 않는다. 일반 공격의 독침과 구분한다.
- 로비·훈련장·대전·봇이 같은 16방향 패턴과 가시 모델을 사용한다. 모드 종료 시 남은 가시와 표시를 정리한다.
- 메인과 베타 시즌 7은 기존 범위 피해 도약을 유지한다. 이번 변경은 베타 시즌 8에 먼저 적용한다.
