# Crimson

메인 캐릭터. 넓은 근접 3연타와 직선 궁극기를 쓰는 브루저다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 9,800 / 1.4 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.74초 / 탄약 1개당 0.9초 |

## 일반 공격 — 3연속 펀치

- 사거리 3.5타일의 3연타 근접 공격이다.
- 각 타격 피해는 1,333 / 1,333 / 1,334로 합계 4,000이다.
- 각 타격은 120ms 간격이며, -25도·0도·+25도로 휘두른다.
- 부채꼴 기본 반각은 42도다.

## 궁극기 — KO 스트레이트

- 충전: 명중 9회.
- 전방 크기 6의 펀치로 3,000 피해를 주고 적을 밀쳐낸다.
- 벽도 부술 수 있다.

## 고유 동작·검증 기준

- 일반 공격은 부채꼴 안의 여러 적을 타격한다.
- 파괴된 벽은 장면과 충돌 목록에서 제거하며, 봇 경로탐색에도 즉시 반영한다. 훈련장과 찹 우드에서도 확인한다.
- 캐릭터 선택 잠금, 봇 배정·궁극기 사용, 계정·시즌 통계 연동을 검증한다.
