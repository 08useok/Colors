# Chartreuse

메인 캐릭터. 무작위 탄환으로 전투 양상이 계속 바뀌는 원거리 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 6,200 / 1.0 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.55초 / 탄약 1개당 1.2초 |

## 일반 공격 — 무슨 공격이지?

- 사거리 9.5타일, 속도 22의 무작위 탄환을 발사한다.
- **강화탄**: 2,400 피해.
- **CC탄**: 기본 1,200 피해와 둔화·고장·발각·독·넉백·얼음 중 하나를 부여. 얼음에 걸리면 2초 동안 이동과 공격을 할 수 없다.
- **흑사병탄**: 적중 시 즉사.
- **무탄**: 피해가 없는 빗나간 탄환.

## 궁극기 — 49% 정신 차림

- 충전: 명중 8회.
- 6초 동안 무탄이 나오지 않으며 강화탄·CC탄·흑사병탄이 같은 확률로 나온다.
