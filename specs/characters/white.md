# White (화이트)

정식 시즌 1 신규 캐릭터. **기획 초안 (2026-11-07) — 미구현.** 수치는 구현·시뮬레이션 뒤 확정한다.

실험용 병을 던지고 흰 벌레를 풀어 견제하는 원거리 소환사. 직접 공격과 소환체로 상대를 압박한다.

## 기본 능력치 (초안)

| 항목 | 값 |
|---|---|
| 체력 | 6,200 |
| 이동 배율 | 1.0 |
| 최대 탄약 | 3 |
| 탄약 1개 재장전 | 1.4초 |
| 역할 | 원거리 소환 견제 |

## 일반 공격 — 화이트병 투척

- 실험용 병을 포물선으로 던진다(벽 너머로 던질 수 있음). 사거리 9타일.
- 착탄 지점 반경 1.5타일에 1,400 피해.
- 착탄할 때마다 **흰 벌레 1마리**를 소환한다.

## 흰 벌레 (소환체)

| 항목 | 값 |
|---|---|
| 체력 | 600 (공격받으면 죽음) |
| 이동 배율 | 1.1 |
| 공격 | 가까운 적을 쫓아가 물기, 0.8초마다 300 |
| 추적 거리 | 7타일 |
| 유지 시간 | 6초 |
| 동시 최대 | 6마리 (넘으면 가장 오래된 벌레가 사라짐) |

벌레가 준 피해로는 궁극기가 차지 않는다(초안).

## 궁극기 — 대형 실험병

- 큰 병을 던져 반경 3타일에 2,800 피해.
- 착탄 지점에 **큰 흰 벌레 1마리**(체력 3,000, 1초마다 700, 유지 10초, 이동 배율 0.9)를 소환한다.
- 필요 충전: 일반 공격 6회 적중.

## 가젯 — 벌레 떼

- 다음 일반 공격이 착탄할 때 벌레를 1마리 대신 **5마리** 소환한다.
- 쿨타임 18초.

## 변신

정식 시즌 1 출시 범위에 포함하지 않는다.

## 정할 것

- 모델·애니메이션(투척, 벌레 모델)
- 벌레가 봇 AI의 공격 대상이 되는 기준(살몬 장치처럼 가까우면 공격)
- 꼬리잡기 위치 — 새 캐릭터는 고리에 넣고 모든 연결 240-0을 다시 검증한다.
