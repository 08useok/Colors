# Green

메인 캐릭터. 근접일수록 강한 부메랑과 은신 수풀을 사용하는 견제형 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 8,400 / 1.2 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.45초 / 탄약 1개당 1.0초 |

## 일반 공격 — 부메랑

- 서로 다른 각도로 부메랑 4개를 던진다.
- 편도 기본 피해는 개당 1,000, 사거리는 7타일, 속도는 20이다.
- 3.5타일보다 먼 편도 피해는 62.5%로 감소한다.
- 귀환 부메랑은 편도 피해의 35%를 주며 1.1배 속도로 돌아온다.

## 궁극기 — 은신 수풀

- 충전: 명중 7회.
- 반경 2.2타일 수풀을 10초 동안 만든다.
- 은신 중 AI와 자동 조준의 대상이 되지 않는다.
- 공격하거나 발각 효과를 받으면 3초 동안 노출된다.

## 순차 발사·검증 기준

- 부메랑은 0.08초 간격으로 순차 발사하며, 발사 대기 중에는 메시를 숨긴다.
- 최대 사거리에서 귀환하고 시전자에게 돌아오면 소멸한다.
- 부채꼴 조준선은 실제 발사 각도에 맞추며, 탄약 부족·재장전 상태를 구분해 표시한다.
- 근거리·원거리·귀환 피해, 순차 발사 간격과 봇의 동일한 공격 규칙을 확인한다.
