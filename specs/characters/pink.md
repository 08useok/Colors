# Pink

메인 캐릭터. 적 피해와 아군 회복을 동시에 수행하는 근접 지원형 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 10,500 / 1.3 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.3초 / 탄약 1개당 0.8초 |

## 일반 공격 — 퍼지는 음표

- 반경 4.5타일의 원형 음표 공격이다.
- 적에게 2,100 피해를 주고, 범위 안 아군은 1,400 회복한다.

## 궁극기 — 앙코르!

- 충전: 명중 15회.
- 반경 8타일의 모든 아군에게 12초간 부활 효과를 준다.
- 효과 중 사망한 아군은 그 자리에서 3초 뒤 체력 40%로 부활하고, 부활 뒤 2초간 무적이다.

## 치유 대상·검증 기준

- 찹 우드에서는 같은 팀을 회복하고 상대 팀에 피해를 준다. 팀이 없는 쇼다운에서는 아군 치유가 발생하지 않는다.
- 자신은 일반 공격의 치유 대상에서 제외하며, 회복은 대상의 최대 체력을 넘지 않는다.
- 피해와 아군 회복의 동시 적용, 캐릭터 선택 잠금과 봇 배정을 확인한다.

베타 수치 변경은 [궁극기 밸런스](../beta-ultimate-balance.md)를 참조한다.
