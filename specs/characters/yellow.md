# Yellow

메인 캐릭터. 둔화로 상대 이동을 묶는 중장거리 제어형 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 5,800 / 1.0 |
| 최대 탄약 | 3 |
| 공격 간격 / 발사 준비 / 재장전 | 0.45초 / 0.12초 / 탄약 1개당 0.9초 |

## 일반 공격 — 찌릿찌릿 전기구슬

- 피해 2,200의 전기구슬을 발사한다.
- 사거리 12타일, 투사체 속도 16.
- 적중한 적은 2초 동안 이동속도가 25% 감소한다.

## 특수/궁극기

- 메인 기준 별도 궁극기는 없다.

## 감전·검증 기준

- 공격 타입은 `electric`이며 직선 단발 투사체를 사용한다.
- 감전은 추가 피해 없이 둔화를 적용하고, 재적중 시 중첩하지 않고 지속시간을 갱신한다.
- 조준선은 공격 사거리와 일치하는 직선으로 표시한다. 감전 상태는 노란 플래시 또는 전기 효과로 구분한다.
- 캐릭터 선택, 봇 배정, 기존 통계 보존과 한·영 표시를 확인한다.

베타 궁극기는 [시즌 6 전기 회로](../beta-season-6.md)를 참조한다.
