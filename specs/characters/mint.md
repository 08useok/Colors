# Mint

## 모델 좌표와 크기

- 메인에서 사용하는 `assets/3d/mint/walk-m1s.fbx`, `walk-m2l.fbx`, `walk-m3e.fbx`는 Z-up이다. Three.js r165 FBXLoader로 읽은 뒤에도 같은 축을 유지한다.
- `prepareMintFbx()`에서 원본을 X축 -90도로 보정하고 `MintYUp` 그룹 안에 넣는다. 외부 그룹은 이동·방향 회전·스케일을 담당한다.
- 축 보정 후 크기를 계산해야 한다. 세 파일의 원본 바운딩 크기는 약 `(149.37, 74.24, 190.35)`이고, 보정 후 높이는 190.35다. 원본 Y 두께 74.24를 키로 사용하지 않는다.
- 로비 정규화 기준은 `PREVIEW_HEIGHT = 4.23`, 발 위치는 `PREVIEW_FEET_Y = -1.85`다.
- 시작·반복·정지 애니메이션과 외부 Y축 회전 후에도 머리가 발보다 위에 있는지 검증한다.

베타 시즌 5에 출시된 캐릭터. 메인과 베타 테스트에서 얼음 수치를 누적해 적을 빙결시키는 컨트롤러다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 6,600 / 1.05 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.75초 / 탄약 1개당 1.15초 |

## 일반 공격 — 아이스크림 탄

- 아이스크림 탄을 3발 연속 발사한다.
- 탄환당 피해 700, 사거리 10타일, 속도 20.
- 각 적중마다 얼음 수치가 25 쌓이고, 100이 되면 2초 동안 빙결된다.
- 연속 발사 간격은 120ms다.

## 특수 공격 — 아이스크림 장판

- 충전: 피해를 준 탄환 명중 7회. 장판 피해는 충전하지 않는다.
- 최대 10타일 떨어진 위치에 반경 9타일 장판을 만든다.
- 장판은 10초간 유지되며, 적은 시간이 갈수록 더 빠르게 미끄러진다.
- 매초 300 피해와 얼음 수치 5를 준다.
- 메인과 베타 모두 조준 방향 10타일 앞을 향해 속도 14로 아이스크림을 던진다. 높이 4.2의 포물선을 그리며 벽과 적을 통과하고, 착지 후 0.08초 뒤 장판이 생성된다. 장판의 10초 지속 시간은 생성 시점부터 계산한다.
- 메인에서는 Space/Q 또는 궁극기 버튼으로 사용하며, 충전 완료 후 조준 중에 투척 방향과 착지 범위를 표시한다.
- 빙결 중에는 이동·일반 공격·궁극기 사용이 차단되며, 2초 뒤 해제된다. 얼음 수치와 빙결 상태를 캐릭터 위에 표시한다.
- 사망·부활 시 얼음과 빙결을 초기화하고, 모드 종료 시 장판을 제거한다.
- 얼음 UI는 베타와 같은 체력바 오른쪽의 파란 둥근 배지다. `❄ 25`처럼 현재 수치만 표시하고, 빙결 시 `❄ 빙결`로 바뀌며 수치가 0이면 숨긴다. 빙결 껍질도 베타와 같은 반투명 민트색 면으로 표시한다.
