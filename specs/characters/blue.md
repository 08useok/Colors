# Blue

메인 캐릭터. 긴 사거리와 빠른 재장전으로 압박하는 연사형 원거리 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 4,800 / 1.0 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.3초 / 탄약 1개당 0.5초 |

## 일반 공격 — 스피드 구슬

- 직선 구슬 1발을 발사한다.
- 피해 1,500, 사거리 16타일, 투사체 속도 32.

## 궁극기 — 돌진

- 블루가 바라보는 방향으로 빠르게 굴러 이동한다.
- 이동 중 벽에 닿으면 진행 방향을 반사해 다시 튕겨 나간다.
- 돌진 경로에 있는 적에게 피해를 주고 넉백시킨다.
- 일반 공격을 적에게 4회 적중하면 충전된다.
- 이동 경로와 벽의 각도를 활용해 예상하기 어려운 진입·이탈 경로를 만들 수 있는 이동형 궁극기다.
