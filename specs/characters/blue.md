# Blue

메인 캐릭터. 긴 사거리와 빠른 재장전으로 압박하는 연사형 원거리 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 4,800 / 1.0 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.3초 / 탄약 1개당 0.5초 |

## 일반 공격 — 스피드 구슬

- 직선 구슬 1발을 발사한다.
- 피해 1,500, 사거리 16타일, 투사체 속도 32.

## 특수/궁극기

- 메인 기준 별도 궁극기는 없다.
- 베타 시즌 5에서는 `바운스 샷` 특수 공격을 시험한다.
