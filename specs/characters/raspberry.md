# 라즈베리 (Raspberry) — 전투 계획안

2026-10-20 · 통합 전투 계획 확정 · **2026-11-01 베타 0.9.2 구현(베타 시즌 9 전용)**

## 구현 상태 (베타 0.9.2)

- 아래 확정 수치와 규칙을 공용 전투 엔진(`src/combat/beta6-combat.js`)과 설정(`src/config/raspberry.js`)에 그대로 반영했다. 베타 페이지에서만 로스터에 추가되며, 메인 v1.8.x에는 포함하지 않는다. 2026-11-02부터 꼬리잡기(지정 상성)에 들어간다: **샤르트뢰즈 → 라즈베리 → 옐로**, 두 연결 모두 240승 0패. 봇 전용 설정으로 체력이 낮아도 추격하고 옐로의 전기구슬만 피한다.
- **특성**: 게임에 특성 시스템이 아직 없어 「일반 공격 속박 +1초」를 라즈베리 고유 패시브로 적용했다(일반 공격 속박 1.6초, 궁극기 2초).
- **모델**: 원본 Blender 모델(`output/raspberry/`)은 뼈대가 없는 정적 모델이라, 크림슨·골드처럼 시안 걷기 리그를 라즈베리 색(#d6336c)으로 칠하고 머리 뼈대에 리본·덩굴·열매 장식을 붙였다. 일반 공격 시 소총 소품을 든다. 전용 리그 모델은 추후 교체 대상이다.
- **연출**: 덩굴탄, 감옥 예고(분홍 깜빡임)·영역(가시 울타리·열매), 묶인 대상의 덩굴 고리. 일반 공격 모션 `recoil` 0.1초 발사, 궁극기 모션 `seal` 0.2초 + 예고 0.4초.
- **검사**: `tools/test-raspberry-combat.mjs`(일반 공격·속박·충전·속박 중 행동 규칙·넉백·감옥 판정·감속·지속·교체·시전자 사망). 훈련장 화면 확인 완료. 실제 경기 화면은 확인하지 못했다. 쇼다운 봇은 로스터 앞쪽 9종만 고르므로 라즈베리 봇은 아직 나오지 않는다.

## 역할

긴 사거리의 직선 저격탄으로 적을 묶는 저격·이동 제어형 캐릭터. 궁극기는 원형 내부의 적을 동시에 속박한다.

## 일반 공격 — 덩굴 저격

| 항목 | 확정 계획 |
|---|---|
| 체력 | 4,800 |
| 일반 공격 피해 | 2,050 |
| 사거리 | 18타일 |
| 공격 방식 | 직선형 저격탄 |
| 공격 간격 | 0.8초 (2026-11-01 변경, 기존 2.4초는 재장전 2초보다 길어 탄약이 줄지 않음) |
| 투사체 속도 | 36타일/초 (2026-11-02 상향, 기존 24) |
| 최대 탄약 | 3발 |
| 탄약당 재장전 | 1.2초, 자동 재장전 (2026-11-02 상향, 기존 2초) |
| 탄환 판정 | 지름 0.7타일 (2026-11-02 상향, 기존 0.3) |
| 기본 속박 | 0.6초 |
| 기존 특성 | 일반 공격 속박 지속 +1초, 궁극기에는 미적용 |
| 특성 적용 시 일반 공격 속박 | 1.6초 |

최대 사거리까지 비행 시간은 0.5초다. 공격 간격과 탄약당 재장전은 별개의 시간이다. 3발을 1.6초에 모두 쏘면 재장전(발당 1.2초)을 기다려야 한다.

2026-11-02 상향 근거: 3:3 시뮬레이션(`tools/simulate-beta9-team-modes.mjs`)에서 라즈베리는 명중률 22~27%, 팀 승률 녹아웃 39%·젬 그랩 44%였다. 선딜(0.1초) 제거·체력·피해 단독 상향은 오차 범위 안이었고, 재장전 1.2초 + 판정 지름 0.7 + 탄속 36을 함께 바꾸면 녹아웃 46%·젬 그랩 56%가 됐다.

### 탄환 판정 — 확정

- 벽 또는 첫 적에게 맞으면 사라진다. 기본 관통은 없다.
- 무적 대상에게는 피해·속박·궁극기 충전이 모두 발생하지 않는다.

### 속박 공통 규칙 — 확정

- 속박은 **이동·돌진·점프·순간이동 시작을 금지**한다.
- **조준·일반 공격·제자리 궁극기는 사용 가능**하다. 이동을 수반하는 궁극기의 시작은 허용하지 않는다.
- 적의 넉백에는 밀려난다. 밀린 뒤에도 남은 속박 시간은 유지한다.
- 재속박은 남은 시간에 새 시간을 더하지 않는다. **기존 종료 시각과 새 종료 시각 중 늦은 쪽**으로 갱신한다.
- 일반 공격 특성 +1초는 궁극기 속박에는 적용하지 않는다.

## 궁극기 — 덩굴 감옥

이름을 덩굴 감옥으로 확정한다. 기존 **직선형 덩굴 벽 계획은 폐기**하며, 원형 범위 내부의 적을 한꺼번에 속박한다.

| 항목 | 확정 계획 |
|---|---|
| 설치 사거리 | 10타일 |
| 범위 반지름 | 3.5타일 |
| 발동 방식 | 지정 위치에 예고 표시 후 0.4초 뒤 발동 |
| 최초 피해 | 600 |
| 최초 속박 | 2초, 특성 +1초 미적용 |
| 영역 유지 | 발동 순간부터 총 4초 |
| 후속 감속 | 30% |
| 궁극기 충전 | 일반 공격 6회 적중 |
| 궁극기 자체 재충전 | 없음 |
| 동시 유지 | 영역 하나, 재사용 시 기존 영역 교체 |

### 발동·영역 판정 — 확정

- 발동 순간 범위 안의 적에게만 **최초 600 피해·2초 속박**을 적용한다. 특성으로 3초가 되지 않는다.
- 최초 속박이 끝난 뒤, 영역 안에 있는 동안 **30% 감속**을 적용한다.
- 나중에 들어온 적은 감속만 받는다. 최초 피해·속박은 받지 않는다.
- 재진입해도 최초 피해·속박을 다시 적용하지 않는다.
- 영역을 벗어나면 감속은 즉시 해제한다. 이미 걸린 최초 속박은 남은 시간을 유지한다.
- 피해는 최초 600 한 번뿐이며 지속 피해는 없다.
- 일반 공격 6회 적중으로 완충하고, **기존 베타 충전 배율을 추가 적용하지 않는다**.
- 궁극기 자체로는 재충전하지 않는다.
- 시전자가 죽어도 이미 발동한 영역은 남은 시간 동안 유지한다.
- 벽을 파괴하지 않는다. 효과 중심과 대상 사이에 벽이 있으면 **최초 효과·감속을 차단**한다.

### 범위 안 판정 — 확정 (2026-11-01)

- **캐릭터 중심점**이 반지름 3.5타일 원 안에 있으면 범위 안이다. 몸 반경은 더하지 않는다. 예고 표시 원과 실제 판정이 같다.
- 발동 순간 **공중에 있는 적**(살몬 포획·퍼플 도약 등)은 최초 피해·속박 대상에서 제외한다. 착지 후 영역 안이면 감속만 받는다.
- 발동 순간 **돌진 중인 적**(블루 구르기·크리스탈 돌진 등)은 대상이다. 돌진을 그 자리에서 끝내고 속박한다.
- 경계에 정확히 걸친 경우(거리 = 3.5)는 범위 안으로 본다. 다른 원형 장판과 같은 기준이다.

## 사망·라운드 처리 — 확정

- 사망해도 모은 궁극기 충전량은 유지한다.
- 부활 시 체력·탄약을 전부 회복한다.
- 새 라운드는 **탄약 3발·궁극기 충전 0**으로 시작한다.
- 라운드 종료·모드 전환 시 **탄환·영역·속박·감속을 정리**한다.
- 피격으로는 궁극기를 충전하지 않는다.

## 구현·검증 시 기준

주요 전투 기획은 위 통합안으로 확정했다. 이동 속박과 공격 불가를 별개로 구현하고, 특성 적용·일반 공격/궁극기 연계·재진입·벽 차단·정리 동작을 검증한다. 아직 게임 구현이나 승률 검증은 하지 않았다.
