# 라즈베리 (Raspberry) — 전투 계획안

2026-10-20 · 사용자 제공 계획안 정리 · **미구현**

출시 시즌·레벨 기준은 미정이다. 아래의 **확정**은 기획 결정이며 코드 적용 완료를 뜻하지 않는다. 체력·일반 공격 피해를 제외한 수치는 밸런스 제안이며 시뮬레이션으로 검증하지 않았다.

## 역할

긴 사거리의 직선 저격탄으로 적을 묶는 저격·이동 제어형 캐릭터. 궁극기는 원형 내부의 적을 동시에 속박한다.

## 일반 공격 — 덩굴 저격

| 항목 | 계획 | 상태 |
|---|---|---|
| 체력 | 4,800 | **확정** |
| 일반 공격 피해 | 2,050 | **확정** |
| 사거리 | 18타일 | 제안 |
| 공격 방식 | 직선형 저격탄 | 계획 |
| 공격 간격 | 2.4초 | 제안 |
| 투사체 속도 | 24타일/초 | 제안 |
| 기본 속박 | 0.6초 | 제안 |
| 기존 특성 | 속박 지속 +1초 | 계획안의 특성; 적용 범위 미정 |
| 특성 적용 시 일반 공격 속박 | 1.6초 | 제안 |

제안 수치에서 최대 사거리까지 비행 시간은 0.75초다. 속박은 이동 제어이며 공격 불가와 구분한다. 궁극기 속박 중에는 공격을 허용하고, 일반 공격 속박의 세부 입력 제한은 구현 전 명시한다.

## 궁극기 — 덩굴 감옥 (가칭)

기존 **직선형 덩굴 벽 계획은 폐기**한다. 원형 범위 내부에 있는 적을 한꺼번에 속박하는 궁극기로 변경한다.

| 항목 | 현재 제안 |
|---|---|
| 설치 사거리 | 10타일 |
| 범위 반지름 | 3.5타일 |
| 최초 피해 | 600 |
| 최초 속박 | 2초 |
| 영역 유지 | 4초 |
| 후속 감속 | 30% |
| 궁극기 충전 | 일반 공격 6회 적중 |

발동 시 원형 내부의 적에게 최초 피해와 속박을 적용한다. 속박된 적은 **움직일 수 없지만 공격은 사용할 수 있다**. 유지 영역과 후속 감속의 시작·종료 조건은 아직 정하지 않았다.

## 구현 전 결정할 규칙

- **탄약:** 최대 탄약·재장전 시간. 공격 간격 2.4초와 재장전 시간을 혼동하지 않는다.
- **탄환 판정:** 크기·벽 충돌·관통·여러 대상 적중 여부.
- **특성:** +1초가 일반 공격에만 적용되는지 궁극기에도 적용되는지. 궁극기 최초 속박은 우선 제안값 2초로 기록하며 임의로 3초로 바꾸지 않는다.
- **속박 입력:** 일반 공격·궁극기·이동기·밀치기·순간이동과의 관계. 이동 속박을 이동·공격 동시 금지 상태와 별도로 처리해야 한다.
- **재속박:** 연속 적중 시 지속시간 갱신·합산 여부와 이미 속박된 대상 처리.
- **영역:** 즉시 발동 또는 투척 설치, 발동 지연, 재진입 시 최초 피해·속박 재적용 여부.
- **후속 감속:** 속박 종료 후 남은 영역 시간 동안인지, 영역을 벗어나도 별도 지속되는지.
- **충전:** 6회 적중과 기존 베타 충전 배율의 관계, 궁극기 자체 재충전 여부.

## 살몬과 구분
