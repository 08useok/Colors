# 라즈베리 (Raspberry) — 전투 계획안

2026-10-20 · 통합 전투 계획 확정 · **미구현**

출시 시즌·레벨 기준은 미정이다. 아래 수치와 규칙은 기획으로 확정했으며 코드 적용 완료를 뜻하지 않는다. 시뮬레이션·브라우저로 아직 검증하지 않았다.

## 역할

긴 사거리의 직선 저격탄으로 적을 묶는 저격·이동 제어형 캐릭터. 궁극기는 원형 내부의 적을 동시에 속박한다.

## 일반 공격 — 덩굴 저격

| 항목 | 확정 계획 |
|---|---|
| 체력 | 4,800 |
| 일반 공격 피해 | 2,050 |
| 사거리 | 18타일 |
| 공격 방식 | 직선형 저격탄 |
| 공격 간격 | 2.4초 |
| 투사체 속도 | 24타일/초 |
| 최대 탄약 | 3발 |
| 탄약당 재장전 | 2초, 자동 재장전 |
| 탄환 판정 | 지름 0.3타일 |
| 기본 속박 | 0.6초 |
| 기존 특성 | 일반 공격 속박 지속 +1초, 궁극기에는 미적용 |
| 특성 적용 시 일반 공격 속박 | 1.6초 |

최대 사거리까지 비행 시간은 0.75초다. 공격 간격과 탄약당 재장전은 별개의 시간이다.

### 탄환 판정 — 확정

- 벽 또는 첫 적에게 맞으면 사라진다. 기본 관통은 없다.
- 무적 대상에게는 피해·속박·궁극기 충전이 모두 발생하지 않는다.

### 속박 공통 규칙 — 확정

- 속박은 **이동·돌진·점프·순간이동 시작을 금지**한다.
- **조준·일반 공격·제자리 궁극기는 사용 가능**하다. 이동을 수반하는 궁극기의 시작은 허용하지 않는다.
- 적의 넉백에는 밀려난다. 밀린 뒤에도 남은 속박 시간은 유지한다.
- 재속박은 남은 시간에 새 시간을 더하지 않는다. **기존 종료 시각과 새 종료 시각 중 늦은 쪽**으로 갱신한다.
- 일반 공격 특성 +1초는 궁극기 속박에는 적용하지 않는다.

## 궁극기 — 덩굴 감옥

이름을 덩굴 감옥으로 확정한다. 기존 **직선형 덩굴 벽 계획은 폐기**하며, 원형 범위 내부의 적을 한꺼번에 속박한다.

| 항목 | 확정 계획 |
|---|---|
| 설치 사거리 | 10타일 |
| 범위 반지름 | 3.5타일 |
| 발동 방식 | 지정 위치에 예고 표시 후 0.4초 뒤 발동 |
| 최초 피해 | 600 |
| 최초 속박 | 2초, 특성 +1초 미적용 |
| 영역 유지 | 발동 순간부터 총 4초 |
| 후속 감속 | 30% |
| 궁극기 충전 | 일반 공격 6회 적중 |
| 궁극기 자체 재충전 | 없음 |
| 동시 유지 | 영역 하나, 재사용 시 기존 영역 교체 |

### 발동·영역 판정 — 확정

- 발동 순간 범위 안의 적에게만 **최초 600 피해·2초 속박**을 적용한다. 특성으로 3초가 되지 않는다.
- 최초 속박이 끝난 뒤, 영역 안에 있는 동안 **30% 감속**을 적용한다.
- 나중에 들어온 적은 감속만 받는다. 최초 피해·속박은 받지 않는다.
- 재진입해도 최초 피해·속박을 다시 적용하지 않는다.
- 영역을 벗어나면 감속은 즉시 해제한다. 이미 걸린 최초 속박은 남은 시간을 유지한다.
- 피해는 최초 600 한 번뿐이며 지속 피해는 없다.
- 일반 공격 6회 적중으로 완충하고, **기존 베타 충전 배율을 추가 적용하지 않는다**.
- 궁극기 자체로는 재충전하지 않는다.
- 시전자가 죽어도 이미 발동한 영역은 남은 시간 동안 유지한다.
- 벽을 파괴하지 않는다. 효과 중심과 대상 사이에 벽이 있으면 **최초 효과·감속을 차단**한다.

## 사망·라운드 처리 — 확정

- 사망해도 모은 궁극기 충전량은 유지한다.
- 부활 시 체력·탄약을 전부 회복한다.
- 새 라운드는 **탄약 3발·궁극기 충전 0**으로 시작한다.
- 라운드 종료·모드 전환 시 **탄환·영역·속박·감속을 정리**한다.
- 피격으로는 궁극기를 충전하지 않는다.

## 구현·검증 시 기준

주요 전투 기획은 위 통합안으로 확정했다. 이동 속박과 공격 불가를 별개로 구현하고, 특성 적용·일반 공격/궁극기 연계·재진입·벽 차단·정리 동작을 검증한다. 아직 게임 구현이나 승률 검증은 하지 않았다.

## 살몬과 구분

[살몬](salmon.md)은 무한 지속하는 원형 테두리 장치를 배치한다. 라즈베리는 4초 유지 영역의 **내부 전체**에 최초 제어를 적용하며, 테두리 장치를 파괴하는 시스템으로 만들지 않는다.
