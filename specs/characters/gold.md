# Gold

메인 캐릭터. 광석이 단계적으로 분열하는 연쇄 투사체와 고장 지대를 쓰는 제어형 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 6,200 / 1.0 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.8초 / 탄약 1개당 1.2초 |

## 일반 공격 — 연쇄 금광석

1. **1단계 광석**: 크기 2, 사거리 8타일, 속도 16, 피해 4,000, 착탄 반경 1.5타일.
2. **2단계 분열탄**: 좌우로 분열. 각각 사거리 4타일, 속도 18, 피해 2,000.
3. **3단계 금괴**: 다시 6개로 분열. 사거리 3타일, 속도 20, 피해 1,000.

한 번의 공격으로 최대 6회 궁극기 충전이 가능하다.

## 궁극기 — Malfunction Zone

- 충전: 명중 12회.
- 자신을 따라다니는 반경 3타일 장판을 4초간 만든다.
- 장판 안 적은 공격할 수 없고 이동속도가 50% 감소한다.
