# Ivory

메인 캐릭터. 아이스크림 투척과 지속 장판으로 지역을 통제하는 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 7,200 / 1.0 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.65초 / 탄약 1개당 1.3초 |

## 일반 공격 — 안 녹는 아이스크림

- 사거리 10타일에 포물선으로 아이스크림을 던진다.
- 착탄 시 1,100 피해를 준다.
- 착탄 지점에 반경 2.8타일 장판을 4초간 만들고, 장판은 1초마다 피해를 준다.
- 장판 피해는 중첩되지 않는다.

## 궁극기 — 단체 주문

- 충전: 명중 8회.
- 최대 12타일 떨어진 지점에 아이스크림 5개를 투척한다.
- 중심 1개와 반경 3.2의 대각선 네 방향으로 떨어진다.
