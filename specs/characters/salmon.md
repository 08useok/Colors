# 살몬 (Salmon) — 전투 계획안

2026-10-20 · 사용자 제공 최신 3차안 정리 · **미구현**

출시 시즌·레벨 기준은 미정이다. 아래의 **확정**은 기획 결정이며 코드 적용 완료를 뜻하지 않는다. 수치 제안은 시뮬레이션으로 검증하지 않았다.

## 역할

낚시찌를 곡사로 던져 적을 포획하는 탄약 관리형 캐릭터. 빗나가면 탄약을 잃고, 포획에 성공하면 사용한 탄약을 회복한다.

## 일반 공격 — 낚시 찌 투척

| 항목 | 계획 | 상태 |
|---|---|---|
| 체력 | 7,600 | 제안 |
| 공격 방식 | 곡사형 투척 | 계획 |
| 직접 적중 피해 | 1,200 | 제안 |
| 낙하 범위 피해 | 600 | 제안 |
| 포획 대상 총 피해 | 1,800 | 제안: 직접 적중 + 낙하 범위 피해 |
| 사거리 | 8.5타일 | 제안 |
| 착지 피해 반경 | 1.75타일 | 제안 |
| 공중 띄우기 | 0.85초 | 제안 |
| 공격 간격 | 2초 | 제안 |
| 최대 탄약 | 5발 | **확정** |
| 자동 재장전 | 불가능 | **확정** |
| 포획 성공 시 탄약 회복 | 1발 | **확정** |

낚시찌 투척 → 포획 판정 → 직접 적중·낙하 범위 피해로 이어지는 개념이다. 실제 좌표·적중 순서·포획 조건은 아직 정의하지 않았다. 포획 대상 총 피해 1,800을 유지하도록 직접 피해와 범위 피해의 적용 대상을 구분해야 한다.

### 빗나간 낚시찌 회수 — 추가 확정

- 빗나간 낚시찌를 수동으로 회수할 수 있다.
- 낚시찌가 **근처 1~4타일**에 있을 때 **일반 공격 버튼을 눌러 가져간다**.
- 가까이 가는 것만으로 자동 회수하지 않는다. 회수한 낚시찌는 탄약으로 되돌아온다.
- 탄약이 0발이어도 회수 입력은 가능해야 한다. 자동 재장전 불가능 규칙은 유지한다.
- 한 번에 여러 찌가 있을 때의 선택·회수 개수, 회수와 발사의 입력 우선순위·쿨다운 관계, 회수물 유지·제거 조건은 아직 미정이다.

## 특수 시스템 — Fishing Point 20

| 항목 | 계획 | 상태 |
|---|---|---|
| 궁극기 게이지 최대 | 20포인트 | **확정** |
| 포획 성공 시 충전 | +4포인트 | 제안 |
| 궁극기 사용 조건 | 20포인트 도달 | 계획 |
| 궁극기 사용 비용 | 20포인트 | 계획 |

제안대로라면 0포인트에서 포획 성공 5회로 완충된다. 자동 재장전은 추가하지 않는다. 탄약이 0발이면 새 낚시찌를 발사할 수 없지만, 근처의 빗나간 낚시찌를 일반 공격 버튼으로 회수해 탄약을 되찾을 수 있다. 회수 자체가 포획 성공이나 포인트 획득에 해당하는지는 미정이다.

## 구현 전 결정할 규칙

- **포획 성공:** 직접 적중·착지 범위 적중 중 무엇이 성공인지, 한 투척으로 포획할 수 있는 대상 수.
- **띄우기:** 대상의 수평 이동과 공격 가능 여부, 착지 위치 및 벽·공중 대상 처리.
- **탄약 회복:** 다수 포획 시 투척당 1발인지 대상당 1발인지, 5발 상한과 회복 시점.
- **탄약 0발:** 수동 회수로 복구한다. 회수물이 접근 불가능한 위치에 있을 때의 처리와 부활·라운드 초기화 시 탄약 규칙은 별도로 정한다.
- **장치 판정:** 접촉 피해의 반복 간격, 몸체 충돌 여부·틈새 통과·돌진·점프 처리.
- **설치 제한:** 투척 사거리·속도·대기 시간, 재사용 시 기존 장치 유지·교체, 동시 설치 상한.
- **수명 관리:** 무한 지속과 별개로 설치자 사망·라운드 종료·모드 전환 때의 제거 규칙.
- **충전:** 포획 외 피해·궁극기 접촉·피격의 충전 여부. 기존 베타 충전 배율 적용 여부.

## 라즈베리와 구분

[라즈베리](raspberry.md)는 원형 내부의 적을 한꺼번에 속박한다. 살몬은 원형 테두리의 파괴 가능한 포획 장치와 탄약 회복을 중심으로 설계한다.
