# 살몬 (Salmon) — 전투 계획안

2026-10-20 · 사용자 제공 최신 3차안 정리 · **미구현**

출시 시즌·레벨 기준은 미정이다. 아래의 **확정**은 기획 결정이며 코드 적용 완료를 뜻하지 않는다. 수치 제안은 시뮬레이션으로 검증하지 않았다.

## 역할

낚시찌를 곡사로 던져 적을 포획하는 탄약 관리형 캐릭터. 빗나가면 탄약을 잃고, 포획에 성공하면 사용한 탄약을 회복한다.

## 일반 공격 — 낚시 찌 투척

| 항목 | 계획 | 상태 |
|---|---|---|
| 체력 | 7,600 | 제안 |
| 공격 방식 | 곡사형 투척 | 계획 |
| 직접 적중 피해 | 1,200 | **확정:** 포획 대상 총 피해의 직접 적중분 |
| 낙하 범위 피해 | 600 | **확정** |
| 포획 대상 총 피해 | 1,800 | **확정:** 직접 적중 + 낙하 범위 피해 |
| 사거리 | 8.5타일 | 제안 |
| 착지 피해 반경 | 1.75타일 | 제안 |
| 공중 띄우기 | 0.85초 | **확정:** 포획 대상만 |
| 공격 간격 | 2초 | 제안 |
| 최대 탄약 | 5발 | **확정** |
| 자동 재장전 | 불가능 | **확정** |
| 포획 성공 시 탄약 회복 | 1발 | **확정** |

### 포획 성공 — 확정

- 착지 범위 안에서 **착지 중심에 가장 가까운 적 1명**만 포획한다. 범위 밖 적은 포획하지 않는다.
- 포획 대상은 **총 1,800 피해 + 0.85초 공중 띄우기**를 받는다. 직접 피해 1,200과 범위 피해 600을 합친 값이며 추가로 600을 중복 적용하지 않는다.
- 주변의 다른 적은 **범위 피해 600만** 받으며 포획되지 않는다.
- 포획에 성공한 투척은 **탄약 1발 회복 + 궁극기 4포인트 충전**을 제공한다. 주변 적의 수만큼 보상을 늘리지 않는다.
- 주변 적에게 범위 피해만 준 경우는 포획 성공으로 세지 않으며 위 포획 보상을 지급하지 않는다.
- 이미 공중에 떠 있거나 무적 보호막 상태인 적은 포획하지 않는다. 같은 거리의 유효 대상이 여럿인 경우의 선택 순서는 미정이다.

### 공중 띄우기 — 확정

- 포획되어 떠 있는 **0.85초 동안 이동·일반 공격·궁극기 사용이 불가능**하다.
- 포획 위치에서 **포획 직전 적이 이동하던 방향의 반대쪽으로 2타일 이동해 착지시킨다**.
- **정지한 지 1초 이내**라면 마지막 이동 방향의 반대쪽으로 보낸다. **1초를 초과해 정지했거나 이동 기록이 없으면 살몬에게서 멀어지는 방향**으로 보낸다.
- 벽을 만나면 **벽 앞에 착지**하고, **맵 밖으로는 나가지 않는다**. 벽이나 맵 경계로 인해 이동 가능 거리가 짧으면 2타일을 채우기 위해 관통하거나 경계를 넘지 않는다.
- 공중에 떠 있어도 **다른 공격의 피해는 받는다**. 공중 상태 자체는 무적이 아니다.
- **살몬 일반 공격도 이미 공중에 떠 있는 적을 재포획하지 않는다.** 궁극기 장치의 기존 재포획 금지 규칙도 유지한다.
- **무적 보호막 상태인 적은 포획할 수 없다.** 일반 공격과 궁극기 장치에 공통 적용한다.
- 공중 이동 궤적과 높이, 살몬과 대상이 같은 위치여서 대체 방향도 구할 수 없는 경우의 세부 처리는 미정이다.

### 빗나간 낚시찌 회수 — 추가 확정

- 빗나간 낚시찌를 수동으로 회수할 수 있다.
- 낚시찌가 **근처 1~4타일**에 있을 때 **일반 공격 버튼을 눌러 가져간다**.
- 가까이 가는 것만으로 자동 회수하지 않는다. **낚시찌 1개 회수 시 탄약 1발을 획득한다(확정).** 최대 탄약은 기존 5발이다.
- 탄약이 0발이어도 회수 입력은 가능해야 한다. 자동 재장전 불가능 규칙은 유지한다.
- **회수 범위에 찌가 있고 탄약이 5발 미만이면 발사 대신 회수한다.** 한 번의 입력으로 회수와 발사를 함께 하지 않는다.
- 여러 찌가 있으면 **가장 가까운 찌 1개만** 회수한다.
- **회수에는 일반 공격 쿨다운을 적용하지 않는다.**
- **탄약이 5발이면 회수하지 않고 일반 공격을 발사한다.** 발사는 기존 일반 공격 쿨다운을 따른다.
- **회수로는 궁극기 포인트를 얻지 않는다.**
- 회수물 유지·제거 조건, 같은 거리의 여러 찌 중 선택 순서는 미정이다.

## 특수 시스템 — Fishing Point 20

| 항목 | 계획 | 상태 |
|---|---|---|
| 궁극기 게이지 최대 | 20포인트 | **확정** |
| 포획 성공 시 충전 | +4포인트 | **확정** |
| 궁극기 사용 조건 | 20포인트 도달 | 계획 |
| 궁극기 사용 비용 | 20포인트 | 계획 |

0포인트에서 포획 성공 5회로 20포인트를 채운다. 자동 재장전은 추가하지 않는다. 탄약이 0발이면 새 낚시찌를 발사할 수 없지만, 근처의 빗나간 낚시찌를 일반 공격 버튼으로 회수해 탄약을 되찾을 수 있다. 수동 회수는 적 포획 성공이 아니며 궁극기 포인트를 지급하지 않는다.

## 궁극기 — 월척이다!

| 항목 | 계획 | 상태 |
|---|---|---|
| 유형 | 투척형 설치 궁극기 | 계획 |
| 배치 | 원형 **테두리**에 장치 배치 | 계획 |
| 설치 사거리 | 8.5타일 | **확정** |
| 투척 속도 | 14타일/초 | **확정** |
| 착지 후 설치 대기 | 0.35초 | **확정** |
| 지속시간 | 무한 | **확정** |
| 동시 설치 상한 | 없음 | **확정:** 기존 장치를 유지하며 추가 설치 |
| 사용 1회당 장치 개수 | 8개 | **확정** |
| 설치 반지름 | 3.5타일 | **확정** |
| 장치 접촉 피해 | 900 | **확정:** 기존 700~1,050 조정 범위에서 고정 |
| 장치 접촉 제어 | 포획 + 0.85초 공중 띄우기 | **확정:** 일반 공격의 포획·띄우기 방식 적용 |
| 장치 접촉 탄약 회복·궁 충전 보상 | 없음 | **확정:** 일반 공격의 성공 보상은 적용하지 않음 |
| 접촉 감속 | 30%, 1초 | 제안 |
| 장치 체력 | 각각 900 | **확정** |

원형 내부 전체에 속박을 거는 방식이 아니라 테두리에 있는 개별 장치가 이동을 방해하는 방식이다. 적은 장치를 파괴해 그 자리에 생긴 탈출구를 이용할 수 있다.

### 투척·설치 — 확정

- 최대 8.5타일 거리의 지정 위치로 초당 14타일 속도로 투척한다.
- **착지 지점을 미리 표시**해 적이 설치 전에 피할 수 있게 한다.
- 착지 후 **0.35초 대기**한 뒤, 중심에서 반지름 3.5타일인 원형 테두리에 장치 8개를 설치한다.
- 장치 체력은 각각 900, 접촉 피해도 900으로 고정한다.

### 장치 접촉 — 확정

- 적이 테두리 장치에 접촉하면 일반 공격처럼 **포획하고 0.85초 동안 공중에 띄운다**.
- 접촉 피해는 **900**이다. 일반 공격의 1,800 피해나 주변 600 범위 피해로 바꾸지 않는다.
- 궁극기 장치의 포획에는 일반 공격 포획 보상인 **탄약 +1발·궁극기 +4포인트를 지급하지 않는다**.
- 원형 내부에 서 있다는 이유만으로 전체 적을 포획하지 않는다. 장치 접촉이 발동 조건이다.
- **같은 적의 재포획은 궁극기 전체 장치가 공유하는 대상별 2초 간격**으로 제한한다. 다른 장치에 접촉해도 이 간격을 우회할 수 없다.
- 여러 장치에 동시에 접촉해도 **피해·띄우기는 1회만** 적용한다.
- **공중에 떠 있는 대상은 다시 포획하지 않는다.**
- 기존 **접촉 감속 30%·1초 제안은 삭제하지 않고 유지**한다. 감속 적용 시점과 재접촉 시 갱신 규칙은 미정이다.

### 장치 유지·제거 — 확정

- **장치 하나를 파괴하면 그 자리가 탈출구가 된다.** 파괴된 장치는 자동 복구하지 않는다.
- **살몬이 죽어도 이미 설치한 장치는 유지한다.**
- **라운드 종료·모드 전환 시 설치된 장치를 모두 제거한다.**
- **동시 설치 상한은 두지 않는다.** 궁극기를 다시 사용하면 기존 장치를 유지한 채 새 원형 장치 세트를 추가 설치한다.

## 구현 전 결정할 규칙

- **포획 대상 선정:** 착지 범위 내 최근접 적 1명이라는 기준은 확정. 거리 동률과 포획 제외 상태의 세부 처리를 정한다.
- **띄우기:** 0.85초 이동·일반 공격·궁극기 금지, 공중 피격 허용, 기존 공중·무적 보호막 대상 포획 금지와 역방향 2타일 착지는 확정. 정지 1초 이내에는 마지막 이동 방향을 사용하고, 그 외에는 살몬에게서 멀어지는 방향을 사용한다. 벽 앞·맵 경계 안 착지를 보장한다. 공중 궤적·높이와 같은 위치에서의 대체 방향은 미정이다.
- **탄약 회복:** 한 투척 포획 성공 시 1발 회복과 수동 회수 시 1발 획득은 확정. 포획 보상의 실제 지급 시점은 미정이다. 회수·발사 우선순위는 위 확정 규칙을 따른다.
- **탄약 0발:** 수동 회수로 복구한다. 회수물이 접근 불가능한 위치에 있을 때의 처리와 부활·라운드 초기화 시 탄약 규칙은 별도로 정한다.
- **장치 판정:** 대상별 재포획 2초 간격 공유·동시 접촉 피해/띄우기 1회·공중 대상 재포획 금지는 확정. 재포획 대기 중 피해·감속 처리, 몸체 충돌 여부·틈새 통과·돌진·점프 처리는 미정이다.
- **설치 동작:** 사거리 8.5타일·투척 속도 14타일/초·착지 후 0.35초 대기·반지름 3.5타일에 장치 8개 설치는 확정. 동시 설치 상한 없이 기존 장치를 유지하며 추가 설치한다. 벽·맵 경계와 설치 지형이 겹칠 때의 배치 보정은 미정이다.
- **수명 관리:** 설치자 사망 시 유지, 파괴 시 자동 복구 없음, 라운드 종료·모드 전환 시 전체 제거는 확정이다.
- **충전:** 일반 공격 포획의 +4포인트와 궁극기 장치 접촉의 충전 없음은 확정. 그 외 피해·피격의 충전 여부 및 기존 베타 충전 배율 적용 여부는 미정이다.

## 라즈베리와 구분

[라즈베리](raspberry.md)는 원형 내부의 적을 한꺼번에 속박한다. 살몬은 원형 테두리의 파괴 가능한 포획 장치와 탄약 회복을 중심으로 설계한다.
