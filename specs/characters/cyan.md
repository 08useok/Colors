# Cyan

메인 캐릭터. 넓은 알약 탄막과 넉백 궁극기를 사용하는 제어형 캐릭터다.

| 기본 스탯 | 수치 |
| --- | --- |
| 체력 / 이동속도 배율 | 7,200 / 1.0 |
| 최대 탄약 | 3 |
| 공격 간격 / 재장전 | 0.35초 / 탄약 1개당 0.8초 |

## 일반 공격 — 압축 알약

- 6개의 알약을 가로로 퍼뜨려 발사한다.
- 알약당 피해 750, 사거리 약 8.33타일, 속도 18, 알약 간격 0.75타일.

## 궁극기 — 질풍 강타

- 충전: 명중 6회.
- 전방 10타일, 폭 10타일의 강풍으로 1,300 피해를 주고 적을 8만큼 밀쳐낸다.
- 강풍 속도는 일반 알약 속도의 5/3배다.

## 투사체·모델

- 일반 공격은 조준 방향에 수직으로 알약을 배치하고 평행하게 발사한다 (`attackType: "spreadLine"`).
- 질풍 강타는 벽과 적을 관통하며 경로의 적을 타격한다.
- 궁극기 시각 자산: `assets/vfx/gale-strike.png`.
- 모델 폴더: `assets/3d/cyan/`. `walk-m1s.glb`, `walk-m2l.glb`, `walk-m3e.glb`는 걷기 시작·반복·정지 모션이다.
- 공격 시 양팔을 전방으로 뻗는 뼈대 모션을 이동 모션에 합성한다.

## 검증 기준

- 평행 탄막의 간격, 적중 피해와 궁극기 관통·넉백을 확인한다.
- 캐릭터 선택, 봇 배정, 기존 통계 보존과 한·영 표시를 확인한다.

베타 수치 변경은 [궁극기 밸런스](../beta-ultimate-balance.md)를 참조한다.
