# 베타 새 로그인 방식 시험 — 2026-10-22

`베타시즌 실행.cmd`로 열고 상단 **계정 로그인 → 새 계정 만들기**를 선택한다. 아이디는 영문·숫자·밑줄 3~24자, 닉네임 1~12자, 비밀번호 10~128자다. 로그인 창에서 로그아웃할 수 있다.

## 비밀번호 변경·복구

- 로그인 후 **계정 → 비밀번호 변경·복구 코드**에서 현재 비밀번호와 새 비밀번호를 입력해 변경한다. 다른 모든 로그인 세션과 기존 복구 코드는 무효가 되고 현재 화면의 세션은 새로 발급한다.
- 같은 메뉴에서 현재 비밀번호로 **복구 코드 발급**을 누른다. 192비트 무작위 코드가 한 번 표시되며 파일로 저장할 수 있다. 닫으면 화면의 코드와 비밀번호 입력을 지우고 브라우저 저장소에 코드를 기록하지 않는다.
- 다시 발급하면 이전 코드는 즉시 무효가 된다. DB의 `recovery_codes`에는 SHA-256 해시만 기록한다. 기존 계정에도 이 테이블만 추가하며 계정·저장 데이터는 유지한다.
- 로그아웃 상태에서 **비밀번호를 잊으셨나요?**를 누르고 아이디·미리 보관한 코드·새 비밀번호를 입력한다. 성공하면 코드를 원자적으로 소모하고 모든 세션을 폐기한다. 새 비밀번호로 다시 로그인해야 한다.
- 코드가 없으면 아이디·닉네임만으로 복구할 수 없다. 복구 후에는 로그인해서 새 코드를 발급한다. 비밀번호 변경·복구는 재화·보유 목록·진행도·전적 저장을 변경하지 않는다.
- 민감한 요청은 현재 화면의 계정 ID와 서버 세션이 일치해야 한다. 비밀번호 재확인 및 복구 시도 제한을 적용한다.

## 실제 적용 범위

- Node.js 로컬 서버가 가입·아이디/비밀번호 확인·세션·베타 저장을 처리한다.
- DB는 `.local/beta-auth.sqlite`다. 서버 재시작 후에도 계정과 베타 저장이 유지되며 Git과 정적 파일 제공 대상에서 제외한다.
- 비밀번호는 Node의 scrypt(N=32768, r=8, p=3), 계정별 무작위 16바이트 salt로 해시 처리한다. 세션은 무작위 32바이트이며 DB에는 SHA-256 해시만 저장한다.
- 로그인 쿠키는 HttpOnly·SameSite=Strict, 유효기간 7일이다. 루프백 HTTP 전용 시험 서버이며 외부 공개나 운영 서비스용 배포는 하지 않았다.
- 같은 출처의 JSON 변경 요청만 허용한다. 가입·로그인 시도 횟수 제한, 입력 크기/구조 검사, 계정별 권한 검사와 저장 버전 충돌 감지가 있다.
- 로그인 계정과 기존 게스트 저장은 별도다. 가입 시 게스트 기록을 자동 이전하지 않는다. 로그인 계정은 새 베타 저장으로 시작하며 로그아웃하면 기존 게스트 저장으로 돌아온다.
- 계정 저장은 0.4초 묶음 처리한다. 실패하면 계정 버튼 상태와 계정 창에 오류를 표시하고, 오래된 저장으로 다른 화면의 변경을 덮어쓰지 않는다. 로그아웃은 진행 중인 저장을 기다린다.
- 베타 시즌 8에서만 로그인 UI를 연결했다. 시험 캐릭터·무료 스킨·재화가 포함되는 베타 저장을 메인이나 공식 랭킹으로 이전하지 않는다.

## 검증

- `node tools/test-beta-auth.mjs`: 가입, 중복 아이디, 올바른/틀린 비밀번호, 비밀번호 해시, DB 재개방 후 저장 복원, 세션 쿠키·로그아웃·만료, 계정 격리, 버전 충돌, 요청 출처·입력 검증·로그인 제한 통과.
- `node tools/test-beta-account-browser.mjs`: 실제 베타 페이지의 비밀번호 확인, 가입, 저장 후 새로고침 복원, 게스트 보존, 로그아웃·오류 표시·재로그인 복원, HttpOnly 쿠키 확인. 페이지 오류 0건.
- `node tools/test-beta-recovery.mjs`: 현재 비밀번호 확인, 세션 폐기, 해시 저장·코드 재발급, 동시 복구 요청의 1회 소모, 잘못된 코드·아이디·짧은 비밀번호 거절, 저장 데이터 보존 검증.
- `node tools/test-beta-recovery-browser.mjs`: 실제 변경·비밀번호 확인 불일치·복구 코드 발급/파일 저장·닫을 때 원문 제거·이전 코드 거절·분실 복구·이전 비밀번호 거절·저장 복원 통과. 페이지 오류 0건. [결과](beta-password-recovery-browser.json) · [설정 화면](beta-password-settings.png)
