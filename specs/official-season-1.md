# 정식 시즌 1 기획

**기획 진행 중 (2026-11-07 시작) — 미구현.** 영역별로 질문하며 채운다. 문서 존재를 구현 완료로 간주하지 않는다.

## 테마 — 크리스마스

- 정식 시즌 1의 테마는 **크리스마스**다.
- 로비: 난간의 트로피 자리에 작은 트리, 깃발 자리에 사탕 지팡이와 선물 상자, 북쪽 배경에 반짝이는 거대 트리, 경기장 전체에 눈 (`src/visuals/christmas-lobby.js`).
- 화면: 초록·빨강·금색 색상(`official-season.css`), 「🎄 크리스마스 시즌」 문구, 로딩 화면 「CHRISTMAS · OFFICIAL」.
- 로비 지역 이름: 크리스마스 광장(가운데) · 눈사람 훈련장(서) · 선물 공방(동) · 산타 성 관문(북) · 눈꽃 결투장(남).

## 가젯 시스템 (초안)

브롤스타즈 2025년 개편 방식을 따른다: 판당 횟수 제한 없이 **쿨타임**으로 쓰는 능동 기술.

| 항목 | 내용 |
|---|---|
| 캐릭터당 가젯 | **1개** (고르는 과정 없이 자동 장착) |
| 사용 | 쿨타임이 차면 언제든 사용, 판당 제한 없음 |
| 쿨타임 | 가젯마다 다름 (10~25초 범위) |
| 충전 | 가젯으로 준 피해는 궁극기·변신 게이지를 채우지 않는다 |
| 조작 | 변신 버튼 옆 가젯 버튼, 키보드 E (로비에서 방 입구 앞이면 방 입장이 우선) |

### 로테이션

- 로테이션 대상 6종(녹아웃·젬 그랩·사커 킥·골드 러쉬·찹 우드·핫 존) 중 **3개를 동시에** 연다.
- **6시간마다** 교체한다. 6종이 12시간에 한 바퀴 돈다.
- 교체 시각과 순서는 모두에게 같게(시간 기준) 정해, 누구나 같은 모드를 본다.

### 핫 존 (신규, 브롤스타즈 방식)

| 항목 | 값 |
|---|---|
| 인원 | 3대3 |
| 구역 | 맵마다 1~2개 |
| 점수 | 구역 안에 우리 팀만 있으면 점수가 오른다(두 팀이 함께 있으면 멈춤) |
| 승리 | 먼저 100% 달성, 또는 2분 뒤 점수가 높은 팀 |
| 점수 속도 | 혼자 차지한 구역 하나당 초당 1.25% (구역 하나만 계속 지키면 80초) |
| 구역 위치 | 맵 0: 가운데 1개(반경 4) / 맵 1: 좌우 2개 / 맵 2: 앞뒤 2개 (반경 3) |
| 부활 | 5초 |

## 맵 (방향)

- 모든 모드의 맵을 **광장처럼 넓게** 만든다. 가운데는 탁 트인 광장, 엄폐물과 수풀은 가장자리와 길목에 둔다.
- 크기·모드별 개수·테마는 정하지 않았다. 핫 존 구역(1~2개)과 젬 제단은 광장 한가운데에 둔다.

## 훈련장 (방향)

- 로비 화면의 **「훈련장 가기」 버튼**으로 바로 이동한다(로비를 걸어서 찾아가지 않아도 됨).
- 훈련장에서는 지금처럼 연습 표적, 변신(게이지 없이) 등을 시험한다. 가젯 체험도 여기서 한다.

## 배틀 시스템 (초안)

### 성장 — 파워 1~11

- 브롤스타즈처럼 캐릭터마다 파워 1~11. 코인으로 파워를 올리면 체력·피해가 오른다.
- **파워당 +2%, 파워 11은 파워 1보다 +20%** 강하다(지금 메인의 레벨당 +2%와 같은 비율, 메인은 레벨 1~6으로 최대 +10%).
- **파워 7: 가젯 해금**, **파워 11: 변신 해금**.
- 레벨당 상승 폭과 필요 코인은 재화 설계와 함께 정한다. 밸런스 시뮬레이션의 기준 레벨(현재 6)도 다시 정한다.

### 랭크 — 트로피 + 랭크 모드

- 일반 대전은 지금처럼 **트로피**.
- 따로 **랭크 모드(경쟁전)**: 브론즈~마스터 등급, 시즌마다 초기화.
- **경쟁전은 파워 11 캐릭터만 쓸 수 있다**(파워 10 이하는 선택 불가). 모두 같은 파워라 가젯·변신까지 갖춘 상태에서 실력으로만 겨룬다.
- 등급 수·승급 기준·시즌 보상은 정하지 않았다.

### 매칭 — 실제 플레이어 + 봇 채움

- 멀티플레이 서버로 사람끼리 매칭한다. 트로피(랭크 모드는 등급)가 비슷한 사람끼리 묶는다.
- 정해진 시간 안에 인원이 안 차면 빈자리를 봇으로 채운다.
- 대기 시간·허용 트로피 범위는 구현 때 정한다. 지금 서버 구조: `party/`, `server/`, [시스템](06-systems.md).

## 배틀 패스 (초안)

| 항목 | 내용 |
|---|---|
| 구성 | **무료 줄 + 프리미엄 줄** 2줄 |
| 단계 | 시즌마다 50단계 |
| 진행 | 판을 하면 패스 경험치가 쌓여 단계가 오른다 |
| 무료 줄 | 누구나 받음 |
| 프리미엄 줄 | 보석으로 구매해야 받음 |

| 줄 | 보상 |
|---|---|
| 무료 | 코인 위주, 크레딧, 보석 조금(시즌당 50) |
| 프리미엄 | 코인 더 많이, 시즌 한정 스킨 2개, **30단계에 신규 캐릭터**(블랙 또는 화이트) |

단계별 정확한 배치와 경험치 양은 구현 때 표로 정한다.

## 파워 업그레이드 비용 (초안)

- **코인만** 쓴다. 파워 1→2 20코인부터 점점 올라 10→11은 약 1,500코인, 1→11 합계 약 4,500코인.
- 코인은 판 보상·배틀 패스·일일 보상으로 얻는다. 단계별 정확한 표는 구현 때 정한다.
- **실제 결제는 이번에 만들지 않는다.** 보석 패키지 상점 화면과 가격표만 만들고, 결제 연동(결제 대행사·앱스토어)은 사업자·약관·환불 정책을 준비한 뒤 따로 붙인다.
