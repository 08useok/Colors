## 메인 정식 출시와 공개 베타 종료

정식 시즌 1이 메인에 공개되는 날 공개 베타를 종료한다. 검증은 정식 테스트판 `official.html`에서 계속한다. 테스트판의 스킨은 구매 없이 장착할 수 있고, 메인의 스킨은 시즌별 획득 규칙으로 지급한다.

### 출시 순서

1. 메인 정식판에서 기존 메인 계정의 진행도와 보유 스킨을 확인한다. 테스트판 스킨 해금이 메인에 적용되지 않는지 확인한다.
2. 베타 챔피언스의 결승 집계가 끝나면 우승자, 최종 순위, 토너먼트 대진·결과, 보상 상태가 담긴 스냅샷을 보관한다. 베타 대회는 `/api/champions`와 `beta9-champions-global`을 사용한다. 메인 대회는 `/api/main-champions`와 별도 저장소를 사용한다. 대회가 아직 진행 중이면 종료 날짜와 보상 처리를 확정한 뒤 전환한다.
3. 베타 계정 서버의 전적은 [SQLite 백업·복원 절차](beta8-backup-restore.md)로 보관한다. 게스트 전적과 개인 챔피언스 전적처럼 브라우저에만 있는 기록은 해당 브라우저에서 따로 보존한다. 계정 DB 백업과 브라우저 기록을 각각 확인한다.
4. 메인의 베타 참가 링크를 내리고, 이전 `beta-season.html` 주소와 시즌별 쿼리 주소에는 종료 안내와 메인 이동 링크를 제공한다. 정식 테스트판 진입 경로를 유지한다.
5. 새 메인 세션과 기존 계정으로 메인 진입을 확인한다. 이전 베타 링크에서는 종료 안내가 열리고, 정식 테스트판에서는 모든 스킨을 장착할 수 있는지 확인한다.

## 배틀 시스템 (초안)

### 성장 — 파워 1~11

- 브롤스타즈처럼 캐릭터마다 파워 1~11. 코인으로 파워를 올리면 체력·피해가 오른다.
- **파워당 +2%, 파워 11은 파워 1보다 +20%** 강하다(지금 메인의 레벨당 +2%와 같은 비율, 메인은 레벨 1~6으로 최대 +10%).
- **파워 7: 가젯 해금**, **파워 11: 변신 해금**.
- 레벨당 상승 폭과 필요 코인은 재화 설계와 함께 정한다. 밸런스 시뮬레이션의 기준 레벨(현재 6)도 다시 정한다.

### 랭크 — 트로피 + 랭크 모드

- 일반 대전은 지금처럼 **트로피**.
- 따로 **랭크 모드(경쟁전)**: 브론즈~마스터 등급, 시즌마다 초기화.
- **경쟁전은 파워 11 캐릭터만 쓸 수 있다**(파워 10 이하는 선택 불가). 모두 같은 파워라 가젯·변신까지 갖춘 상태에서 실력으로만 겨룬다.
- 등급(구현): 브론즈 0 · 실버 300 · 골드 600 · 다이아몬드 1,000 · 신화 1,500 · 전설 2,100 · 마스터 2,800점. 승 +25, 패 -15, 0점 아래 없음. 시즌 보상은 정하지 않았다.

### 매칭 — 실제 플레이어 + 봇 채움

- 멀티플레이 서버로 사람끼리 매칭한다. 트로피(랭크 모드는 등급)가 비슷한 사람끼리 묶는다.
- 정해진 시간 안에 인원이 안 차면 빈자리를 봇으로 채운다.
- 대기 시간·허용 트로피 범위는 구현 때 정한다. 지금 서버 구조: `party/`, `server/`, [시스템](06-systems.md).
- 구현 (2026-11-08, 경쟁전만): 같은 모드끼리, 점수 범위 처음 ±150점 → 5초마다 +75점(최대 ±600점), 서로의 범위 안에 있어야 묶인다. 6명이면 바로, 가장 오래 기다린 사람이 **20초**를 넘기면 모인 사람만으로 시작하고 빈자리는 봇. 팀은 점수 순 지그재그(1·4·5등 대 2·3·6등), 2명이면 서로 상대 팀. 혼자면 지금처럼 봇과 바로 시작, 서버 연결이 안 되면 봇 경기.
- 전투 동기화: 호스트(팀 a의 최고 점수 플레이어) 브라우저가 엔진·봇·목표·승패를 계산하고 초당 15회 상태를 보낸다. 다른 사람은 자기 캐릭터만 움직이며 위치·공격·궁극기·가젯·변신을 호스트에 보낸다. 팀 b는 경기장을 180° 돌려 자기가 아래쪽(우리 팀)에 보인다. 결과는 호스트 → 서버 → 모두에게 같게 전달. 게스트가 나가면 그 자리를 봇이 이어받고, 호스트가 나가면 다른 사람에게는 무효(점수 변동 없음).
- 코드: 규칙 `src/official/ranked-match.js`, 연결 `src/official/ranked-net.js`, 서버 `party/server.js`(방 `ranked`). 테스트 `tools/test-ranked-matchmaking.mjs`, `tools/test-ranked-server.mjs`(서버 필요), `tools/qa-ranked-two-browsers.mjs`(서버·페이지 필요).

## 파워 업그레이드 비용 (초안)
