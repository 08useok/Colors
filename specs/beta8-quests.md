# 시즌 8 퀘스트·보상 트랙 — 베타 0.8.41

## 점수

시즌 포인트 = 처치 수 + 실제 스킬 회복량 / 2,000 + 실제 적 캐릭터 피해량 / 1,000.

세 항목의 소수 점수를 합산한다. 반올림은 표시할 때만 소수 둘째 자리까지 하며, 원본 처치·회복·피해 총량을 저장해 경기 사이와 재접속 후에도 남은 진행도를 유지한다. 예: 2킬 + 회복 3,000 + 피해 1,500 = 5점.

## 집계 범위

- 시즌 8 베타 경기에서 플레이어 본인이 준 적 캐릭터 피해·마지막 타격 처치와 아군에게 준 스킬 회복만 기록한다.
- 피해는 적의 남은 체력, 회복은 아군의 잃은 체력까지 인정한다. 아군 공격·무적 대상·죽은 적 재타격은 추가 점수를 주지 않는다.
- 자연 회복, 다른 AI의 실적, 연습 표적, 설치물·목표물 피해와 부활은 집계하지 않는다.
- 정상 종료한 경기만 시즌 누적에 반영한다. 패배도 인정하며, 중도 퇴장과 진행 중 다른 모드로 전환한 경기는 반영하지 않는다.
- KNOCKOUT 라운드 사이에는 경기 통계를 유지한다. 종료 시 한 번 합산하며, 새 경기에서 경기 통계를 초기화한다.

## 화면과 저장

기존 시즌 업데이트 메뉴를 `시즌 퀘스트`로 연결한다. 업데이트 안내는 퀘스트 화면의 `시즌 업데이트 보기` 버튼으로 계속 열 수 있다.

시즌 누적 10·30·60점과 100점 간격의 100~10,000점으로 총 103단계를 구성한다. 20단계씩 6페이지로 표시하며 처음·이전·다음·10,000점 보기로 이동한다. 전체 트랙 진행도는 10,000점까지만 표시하고 원본 점수 누적은 계속 유지한다.

| 단계 | 지급 보상 |
| --- | --- |
| 10·30·60점 및 일반 100점 간격 | 코인 50 |
| 500점 배수 (1,000점 배수 제외) | 코인 100 + β 크레딧 50 |
| 1,000점 배수 (10,000점 제외) | 코인 250 + β 크레딧 100 |
| 10,000점 | 코인 1,000 + β 크레딧 500 |

보상은 개별 수령 또는 받을 수 있는 보상 모두 받기로 지급한다. 점수는 소비하지 않는다. 보상은 단계당 한 번만 지급하고, 받은 단계는 별도 저장 필드 beta8QuestClaimed로 보존한다. 전체 합계는 코인 8,400 + β 크레딧 1,900이다. 기존 포인트는 그대로 인정하며 기존 재화·다른 보상 수령 기록은 유지한다.

`beta8Quests`에 원본 누적치를 저장하며, 기존 게스트·계정별 저장 경로와 서버 저장 동기화를 이용한다. 기존 캐릭터·재화·전적은 유지한다. 메인은 시즌 8 업데이트 당일에 이식한다.

## 검증

- `node tools/test-beta8-quests.mjs`: 공식·소수 이월·잘못된 값·저장 왕복·실제 회복량.
- `node tools/test-beta6-combat.mjs`: 기존 공유 전투 회귀.
- Ego 브라우저: 실제 KNOCKOUT 전투 처리에서 1킬 + 회복 250 + 피해 2,500 = 3.625점, 중복 종료 방지, 중도 퇴장 제외, 새로고침 후 저장, 10점 달성 표시 확인. [검증 결과](beta8-quests-browser.json)
- 보상 트랙: Ego에서 잠긴 보상, 개별 수령, 중복 클릭, 일괄 수령, 최종 10,000점 보너스, 103단계 지급 합계 및 새로고침 후 수령 기록을 확인했다. [보상 트랙 검증](beta8-quest-track-browser.json)
- 화면 캡처는 도구 시간 초과로 확보하지 못했다. 화면 문구·진행도 값과 오류 목록은 Ego에서 확인했다.

재검증은 `node tools/serve-beta-quest-qa.mjs`로 별도 검증 서버를 열고 Ego에서 `tools/test-beta8-quests-ego.mjs`를 실행한다. 검증용 내부 접근은 서버에서만 주입하며 게임 배포 모듈에는 포함하지 않는다.

보상 트랙 Ego 재검증 스크립트: `tools/test-beta8-quest-track-ego.mjs`.
