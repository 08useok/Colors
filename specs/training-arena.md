# 훈련장 개편 기획

## Summary

메인 게임에서 훈련장을 별도 진입 공간으로 제공한다. 사용자가 캐릭터 선택 화면에서 선택한 캐릭터로 훈련장에 들어가며, AI 전투는 실행하지 않고 훈련 봇만 배치한다.

## Scope

- 캐릭터 선택 버튼 옆에 `훈련장` 버튼 배치
- 훈련장 전용 위치와 전용 맵 표시
- 선택한 캐릭터로 훈련장 진입
- 훈련 봇 배치
- 훈련장 전용 바닥·벽 디자인

## Non-goals

- 일반 쇼다운·찹 우드 경기 규칙 변경
- 훈련장 봇의 전략 AI 구현
- 훈련장 전용 보상·전적 추가

## Requirements

### 1. 진입 UI

- 캐릭터 선택 버튼 옆에 `훈련장` 버튼을 배치한다.
- 버튼을 누르면 매치메이킹 없이 즉시 훈련장으로 이동한다.
- 훈련장 진입 시 현재 선택한 캐릭터를 기준으로 플레이어를 생성한다.
- 이전에 선택했던 캐릭터나 로비 상태가 훈련장에 남아 있지 않아야 한다.

### 2. 훈련장 플레이어

- 훈련장에는 플레이어 1명만 생성한다.
- AI 플레이어는 생성하지 않는다.
- 플레이어는 WASD 이동, 조준, 일반 공격, 궁극기를 사용할 수 있어야 한다.
- 훈련장 퇴장 후 로비로 돌아오면 기존 로비 상태를 정상 복구한다.

### 3. 훈련 봇

- 훈련 봇 유형은 2가지다.
- 거대 봇 1종: 중앙에 배치한다.
- 짤짤이 봇: 4줄 × 5명, 총 20명을 배치한다.
- 봇은 훈련 대상이며 일반 AI 전투 로직을 사용하지 않는다.
- 봇은 체력바를 표시하고, 처치 시 지정된 방식으로 재생성할 수 있어야 한다.

### 4. 훈련장 맵

- 본 게임 전장과 별도의 훈련장 위치·씬을 사용한다.
- 벽은 회색으로 표시한다.
- 바닥은 검은색을 기본색으로 사용한다.
- 바닥에는 회색 줄무늬를 반복 배치한다.
- 훈련장 입장 시 본 게임 맵은 숨기고 훈련장 맵만 표시한다.

## State separation

- 훈련장 맵 가시성, 충돌 목록, 봇 목록, 투사체, 장판, 카메라 상태를 일반 경기 상태와 분리한다.
- 훈련장 진입 시 이전 모드의 맵·봇·투사체·효과를 초기화한다.
- 훈련장 퇴장 시 훈련장 객체를 정리하고 로비로 복귀한다.

## Acceptance Criteria

1. 캐릭터 선택 화면에서 선택 버튼 옆에 `훈련장` 버튼이 보인다.
2. `훈련장` 클릭 시 매치메이킹 없이 즉시 훈련장 화면으로 이동한다.
3. 선택한 캐릭터가 Ivory가 아니어도 해당 캐릭터가 훈련장에 생성된다.
4. 훈련장에 AI 플레이어가 추가로 생성되지 않는다.
5. 거대 봇 1개와 4줄 × 5명의 짤짤이 봇이 보인다.
6. 벽은 회색, 바닥은 검은색, 바닥 줄무늬는 회색으로 보인다.
7. 이동·일반 공격·궁극기가 동작한다.
8. 브라우저 콘솔에 훈련장 진입 후 반복 오류가 없다.
9. 훈련장 퇴장 후 로비와 캐릭터 선택 상태가 정상이다.

## Validation

- 캐릭터 선택: Red, Pink, Ivory 각각으로 진입 테스트
- 봇 수량: 거대 1개, 짤짤이 20개 확인
- 화면 캡처로 맵 색상·줄무늬·봇 배치 확인
- 이동·공격·궁극기 수동 테스트
- 훈련장 진입/퇴장 반복 테스트
- 브라우저 콘솔 error/warn 확인
