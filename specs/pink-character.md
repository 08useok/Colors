# Pink 캐릭터 (광역 치유 + 근접 피해)

## 개요
근접 범위에서 팀원을 치유하고 적에게 피해를 동시에 주는 서포터.
찹 우드에서 팀 생존력을 극대화한다.

---

## 스탯

| 항목 | 값 |
|------|-----|
| 체력 | 11,500 (전체 최고) |
| 이동속도 | 1.4 (빠름, Red와 동일) |
| 사거리 | 4.5 |
| 재장전 | 0.4s |
| 공격 쿨다운 | 0.2s |
| 색상 | `0xF4CDD3` |
| 등급 | 희귀 (200크레딧) |

---

## 공격 방식 — 힐 서클 (heal_circle)

반경 4.5타일 원형 범위 공격. 팀원 회복 + 적 피해 동시 적용.

| 항목 | 값 |
|---|---|
| 공격 타입 | `heal_circle` |
| 범위 | 4.5타일 반경 |
| 적 피해 | 2,400 |
| 팀원 회복 | 알파 2,400 / 베타 1,600 |

### 대상 규칙

| 모드 | 적 | 팀원 |
|---|---|---|
| 찹 우드 | 상대 팀 플레이어 → 2400 피해 | 같은 팀 플레이어 → 알파 2400 회복 |
| 쇼다운 | 범위 내 모든 적 → 2400 피해 | 팀 없음 → 치유 무효 |

- 자기 자신은 치유 대상에 포함되지 않음
- 치유는 `maxHealth` 초과 불가

## Regression Guard
- 기존 캐릭터 밸런스 변경 없음
- `state.chopWoodMode` 분기만 추가 — 기존 쇼다운 로직 변경 없음

## Acceptance Criteria
- [ ] 공격 발동 시 4.5타일 이내 적에게 2400 피해가 적용된다
- [ ] 알파 찹 우드에서 4.5타일 이내 팀원 체력이 2400 즉발 회복된다
- [ ] 베타 테스트에서는 회복량이 1600으로 적용된다
- [ ] 쇼다운에서는 치유 대상이 없어 회복이 발생하지 않는다
- [ ] 치유는 maxHealth를 초과하지 않는다
- [ ] 자기 자신은 치유되지 않는다
- [ ] 로비에서 Pink 카드 표시 + 미보유 시 잠금
- [ ] 봇이 Pink로 배정될 수 있다
