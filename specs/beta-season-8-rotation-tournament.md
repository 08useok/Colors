# 베타 시즌 8 — 로테이션 모드 3단계 토너먼트 (기획 메모)

## 상태

**구현 대상 아님.** 로스터가 16명이 채워질 때까지는 이 문서로만 남겨둔다.
현재(2026-08) 캐릭터 수는 10명(Red/Green/Blue/Orange/Yellow/Cyan/Purple/Pink/Crimson/Gold) +
논의 중인 아이보리(시즌 3) 까지 최대 11명 — 16명 채우려면 시즌이 여러 번 더 지나야 한다.

## 개요

기존 로테이션 모드(`ROTATION_CHAR_ORDER` 8명, 매일 승률 최하위 1명 탈락, `RotationStats` Durable
Object로 전역 집계)를 베타 시즌 8에서 3단계 토너먼트 구조로 확장한다.

## 3단계 구조

### 1단계 — 두 그룹 독립 로테이션

- 전체 로스터를 8명씩 두 그룹으로 나눠 **각 그룹이 독립적으로** 로테이션 진행
- 기존 매일 탈락과 달리, **2일마다** 그룹별로 승률 최하위 캐릭터 1명 탈락
- 그룹 구성: **미정** — 로스터가 16명이 되기 전까지 정할 수 없음

### 2단계 — 병합 + 신규 캐릭터 합류

- 각 그룹이 4명까지 줄어들면(그룹 A 4명 + 그룹 B 4명 = 8명) 새 모드 하나를 만들어 병합
- 병합된 모드에 **신규 캐릭터 2명**을 추가해 총 10명으로 로테이션 계속
- 신규 캐릭터 2명: **미정** — 사용자가 직접 지정 예정

### 3단계 — 최종 결승

- 병합된 모드에서 **1명만 남을 때까지** 순위 경쟁 계속
- 최종 우승자는 **정규(라이브) 게임에 영구 신규 능력 획득** — 베타가 아니라 본 게임에 반영되는 보상

## 결정 안 된 것 (로스터가 16명 될 때 다시 논의)

- [ ] 1단계 두 그룹의 정확한 캐릭터 구성 (8명 + 8명)
- [ ] 2단계에서 합류할 신규 캐릭터 2명이 누구인지
- [ ] "2일마다 탈락" 판정 기준 — 기존 로테이션처럼 승률 하위 1명인지, 다른 지표(판수, MVP 등) 반영 여부
- [ ] 최종 우승자가 획득하는 "새 능력"의 구체적 내용
- [ ] 기존 `RotationStats`/`ROTATION_CHAR_ORDER` 구조를 그대로 확장할지, 별도 시스템으로 새로 만들지
