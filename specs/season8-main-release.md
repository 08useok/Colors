## 제외한 범위

- 메인·베타 공유 계정 DB와 아이디·비밀번호 로그인: 공용 클라우드 DB가 배포되지 않아 메인 기존 계정 저장을 유지한다.
- 베타 전적(최근 20경기)·로컬 베타 랭킹: 베타 로컬 인증 서버에 의존한다. 메인은 기존 통계·리더보드를 유지한다.
- 베타 자유 이동 로비의 두 방·할로윈 로비 장식: 메인 로비 흐름을 대체하는 기능이 아니다.
- 공개 상태의 KNOCKOUT 관전 카메라: 탈락한 플레이어는 자기 위치에서 대기한다(베타는 아군 관전).
