# 살몬 착지 피해와 상성 목표

## 최신 조정: 일반 공격 / 궁극기 3000

- 일반 공격 최초 포획 피해 3000(직접 2400 + 범위 600), 궁극기 접촉 피해 3000. 착지 600을 더하면 각각 합계 3600. 주변 범위 피해와 장치 체력 900은 유지.
- 궁극기는 투척물 착지 후 대기 0초. 투척 준비/비행은 유지하고 지면 도착 시 바로 장치 생성.
- 같은 조건 1920회 재시험: 골드 100%, 그린 69.2%, 핑크 55.8%, 크림슨 40.8%, 샤르트뢰즈 30.8%, 시안 26.7%, 라벤더 18.3%, 오렌지 10%, 옐로 7.5%, 레드 4.2%, 나머지 6명 0%.
- 확정 목표 고리는 **아이보리 → 살몬 → 골드 → 그린**이다. 살몬은 아이보리에게 약하고 골드에게 강한 상성으로 편입한다. 현재 봇 시험에서 아이보리의 살몬 상대 120전 120승과 살몬의 골드 상대 120전 120승을 관측했다. 모든 맵과 실제 이용자의 승률을 보장하는 뜻은 아니다.
- Ego space 13: 최초 3000 + 착지 600, 지속 1.2초 / 높이 4.5 재검증. 최신 JSON 두 파일을 갱신했다.
- 아래는 이전 수치의 기록이다.

## 2026-10-25 구현

- 일반 공격 포획: 최초 1800 + 착지 600 = 기본 합계 2400.
- 궁극기 장치: 접촉 900 + 착지 600 = 기본 합계 1500. 접촉한 장치는 즉시 파괴하는 기존 규칙 유지.
- 띄우기 1.2초, 최대 높이 4.5타일 유지.
- 착지 피해는 포획 대상에게만 한 번, 기존 `hit` 경로로 처리. 피해 감소·무적을 존중하며 이미 사망한 대상에는 적용하지 않음. 추가 궁극기 충전 없음. 일반 공격과 궁극기 설정의 `landingDamage`로 각각 정의하여 레벨 배율도 적용.
- 살몬 봇의 일반 공격은 투척 준비 시간과 비행 시간에 따른 이동 예측 조준을 적용. 플레이어 조준점은 그대로 유지. 상성별 피해 배율은 추가하지 않음.
- 착지로 마지막 적이 죽은 직후 대상 없이 궁극기를 시도하는 오류를 방어.

## 목표

기존 16캐릭터 상성 고리의 `아이보리 → 골드` 사이에 살몬을 삽입하여 **아이보리 → 살몬 → 골드 → 그린**으로 확정한다. 아이보리의 목표 승리 상대와 골드의 목표 패배 상대만 살몬으로 변경하며, 나머지 기존 캐릭터의 목표 관계는 유지한다. 화살표는 왼쪽이 오른쪽에게 유리하다는 설계 목표다.

`src/config/beta8-counter-targets.js`는 17캐릭터 목표만 선언하며 실제 전투에 강제 승패·상대별 보너스를 주지 않는다.
