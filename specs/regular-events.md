# 정규 이벤트

## 확정 운영 원칙

모든 게임 모드는 **정규 이벤트**로 운영한다. 출시 시즌은 최초 도입 기록이며, 모드의 이용 가능 기간이 아니다. 시즌이 바뀌거나 종료되어도 출시된 모드를 숨기거나 다른 모드로 대체하지 않는다.

시즌은 맵 테마·음악·스킨·퀘스트를 바꿀 수 있다. 시즌 보상 일정과 캐릭터 출시·밸런스, 시즌별 전적 집계는 기존 별도 규칙을 따른다. 한 경기의 제한 시간은 모드 규칙이므로 유지한다.

## 목록과 현재 진입 위치

| 정규 이벤트 | 기본 규칙 | 메인 | 베타 테스트 |
|---|---|---|---|
| 쇼다운 | 최후 생존 | 모드 선택 | 쇼다운 버튼 |
| 쇼다운+ | 쇼다운에 처치당 트로피 +2 | 독립 선택 미구현 | 쇼다운+ 버튼, 모든 테스트 시즌에서 선택 |
| 찹 우드 | 3v3 상대 나무 파괴 | 모드 선택 | 찹 우드 버튼, 전용 30×60 맵 |
| 테이크다운 | 중앙 보스 처치·기여 순위 경쟁 | 모드 선택 및 정규 이벤트 카드 | 베타 자체 구현 없음 |
| 골드 러쉬 | 금 10개 확보 후 10초 방어 | 모드 선택 | 골드 러쉬 버튼 |
| 사커 킥 | 3v3, 3분, 2골 선승 | 모드 선택 | 사커 킥 버튼, 시즌 제한 없음 |
| 젬 그랩 | 3v3, 젬 10개 확보 후 15초 방어 | 메인 이식 미완료 | 젬 그랩 버튼, 골드 러쉬와 별도 선택 |

훈련장은 시즌에 관계없이 이용하는 연습 기능이다. 로테이션 토너먼트도 향후 도입 시 정규 이벤트 분류를 따르지만, [기획 메모](beta-season-8-rotation-tournament.md)의 미구현 상태와 미정 규칙을 그대로 유지한다.

## 구현 기준

- 메인 골드 러쉬 버튼에서 시즌 2·3 표시 조건을 제거한다.
- 테이크다운 카드의 종료 날짜와 잔여 시간에 따른 숨김을 제거하고 `상시 운영`을 표시한다.
- 베타의 골드 러쉬·젬 그랩을 별도 버튼으로 제공한다. 시즌 선택으로 버튼의 모드가 바뀌지 않는다.
- 베타 사커 킥의 시즌 6 진입 제한을 제거한다.
- 베타 쇼다운+의 처치 보너스는 선택한 규칙으로 판단한다. 시즌 5 여부로 강제하지 않는다.
- 캐릭터 로스터와 수치, 계정 저장은 선택한 시즌의 테스트 설정을 사용한다.
- 정규 이벤트 분류와 실제 구현 여부를 구분한다. 미구현 이벤트를 실행 가능한 것으로 안내하지 않는다.

## 모드별 맵 3종

구현된 정규 모드는 기본 맵 1개와 벽 중심·부쉬 중심 맵을 각각 1개씩 제공한다. 경기 시작 전 `맵 유형`에서 선택한다. 멀티플레이는 동일 모드·동일 맵 선택끼리 매칭하며, 서버가 확정한 맵 번호를 참가자 모두에게 전달한다.

| 모드 | 기본 맵 | 벽 많음 · 부쉬 적음 | 부쉬 많음 · 벽 적음 |
|---|---|---|---|
| 쇼다운 | 마지막 광장 | 철벽 골목 | 안개 호수 |
| 쇼다운+ | 승부의 거리 | 포위된 구역 | 그림자 수풀 |
| 찹 우드 | 톱밥 숲 | 목재 미로 | 깊은 숲 벌목지 |
| 골드 러쉬 | 황금 광맥 | 금고 요새 | 황금 오아시스 |
| 사커 킥 | 킥오프 광장 | 반격의 성벽 | 풀숲 골문 |
| 젬 그랩 | 황금 신전 | 봉인의 미로 | 비밀 정원 |
| 테이크다운 | 거인의 광장 | 강철 포위망 | 수호자의 숲 |

- 쇼다운+·젬 그랩은 베타, 테이크다운은 메인에서 제공하는 현재 구현 범위를 유지한다.
- 기본 맵은 기존 모드 지형을 유지한다. 베타 골드 러쉬는 로비와 분리한 40×40 경기장을 사용한다.
- 추가 지형은 모드 크기에 맞춰 배치하고 스폰·목표물 주변을 비운다. 중앙 이동로와 골대 진입로를 유지한다.
- 부쉬 중심 쇼다운·쇼다운+·골드 러쉬·테이크다운에는 외곽 호수를 배치한다. 호수는 통행을 막고 부쉬는 근거리 감지·공격/피격 발각 규칙을 따른다.
- 봇은 지형을 우회하고 사커 공은 내부 벽에 튕긴다. 시즌 변경으로 이 맵 목록을 제한하지 않는다.
