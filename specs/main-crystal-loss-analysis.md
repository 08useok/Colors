# 크리스탈 패배 원인과 궁극기 폭 조정

2026년 10월 17일 · 메인 15종 설정, 크리스탈 대 크림슨

이 문서는 궁극기 폭을 변경한 시점의 추적 기록입니다. 이후 2단계 조각 중첩을 1→3회로 늘린 비교에서는 452승 148패(75.3%)였습니다. [후속 결과](main-crystal-fragment-verification.json)를 참고하세요.

추가로 3단계 조각을 최대 4회 적중으로 변경한 결과는 570승 30패(95.0%)입니다. [최신 3단계 결과](main-crystal-shard-verification.json)를 참고하세요.

## 패배 원인

6레벨·궁극기 충전 0 시작·거리 10/13/16타일·조준 오차 2종·시드 50개·양쪽 순서 교환으로 600회를 추적했습니다. 443승 157패였고 시간 초과는 없었습니다.

**157패 모두 크리스탈 궁극기를 한 번도 쓰지 못한 채 크림슨 궁극기로 마무리됐습니다.** 궁을 사용하고 빗맞혀서 진 경기는 없었습니다.

| 사망 시 궁 충전 | 패배 수 | 관측 내용 |
|---:|---:|---|
| 0/6 | 29 | 일반 공격도 한 번도 맞히지 못함 |
| 3/6 | 119 | 한 차례의 3단계 적중에 해당하는 충전만 확보 |
| 5/6 | 5 | 완충에 한 칸 부족 |
| 6/6 | 4 | 완충 다음 프레임에 크림슨 궁이 먼저 처리되어 사용 전에 사망 |

완충 4회는 모두 크림슨이 먼저 추가된 순서였습니다. 시뮬레이션의 액터 순차 처리 영향이 포함되므로 실제 모든 상황에서 크림슨이 먼저 쓴다는 뜻은 아닙니다.

첫 수정탄 2000→2200 버프 이후에도 이 157패에서 살아남은 크림슨의 체력은 3410~11550이었습니다. 추가 피해가 처치까지 도달하지 않았고, 궁극기 충전은 피해량이 아닌 적중 횟수로 증가하므로 충전 부족도 해소하지 못했습니다.

## 적용한 궁극기 폭

- 메인 궁극기 조준선: 가로 **1.1→2.2타일**.
- 기존 전투 판정은 폭과 무관하게 지정 적을 즉시 묶었습니다. 메인에만 폭 설정을 추가하고, 조준 방향의 18타일·가로 2.2타일 안에 있는 첫 적을 분석하도록 연결했습니다.
- 폭 밖·뒤쪽·사거리 밖은 빗나가며 궁 충전을 유지합니다. 분석 중인 적은 중복 선택하지 않습니다.
- 베타는 폭 설정이 없으므로 기존 지정 대상 방식과 1.1타일 조준선을 유지합니다.
- 크리스탈의 충전 요구량·처형 시간과 크림슨 수치는 바꾸지 않았습니다.

봇은 원래 대상 중심으로 궁을 사용하므로 가로 폭 증가는 이번 패배 원인을 해결하지 않습니다. 같은 600회를 다시 실행해도 **443승 157패, 73.8%**였습니다.
