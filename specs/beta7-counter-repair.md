# 베타 시즌 7 지정 상성 복구

## 적용한 변경

| 캐릭터 | 항목 | 이전 → 변경 |
|---|---|---|
| 민트 | 일반 탄환 피해 | 700 → 1000 |
| 시안 | 탄환 1발 피해 | 650 → 700 |
| 샤르트뢰즈 | 체력 | 6800 → 8200 |
| 크림슨 | 궁극기 충전 요구량 | 7 → 3 |
| 크리스탈 | 일반 공격 사거리 | 11 → 12타일 |

베타 시즌 7의 플레이어·봇·훈련장이 같은 설정을 사용한다. 궁극기 사용 조건 등 별도 봇 전용 규칙은 추가하지 않았다. 후퇴 상대 추적도 다시 넣지 않았다. 옐로우의 궁극기 충전량은 2칸으로 유지한다. 상성별 피해 보정은 사용하지 않는다.

## 비교 과정

총 218개 후보를 비교했다. 먼저 조건당 3회로 후보를 추린 뒤 최종 후보는 조건당 30회, 상대별 360경기로 확인했다. 같은 전투 생성 순서·거리·오차·시드를 사용하고, 변경 캐릭터와 연결된 모든 지정 상성이 이전보다 나빠지는 후보는 제외했다. 예를 들어 옐로우 탄환 속도를 18로 올리면 아이보리 상대는 100%가 되지만 샤르트뢰즈→옐로우가 악화되어 적용하지 않았다.

남은 패배를 재현하면 민트·샤르트뢰즈는 서로 후퇴한 뒤 독가스가 승패를 정하는 사례가 있었고, 크림슨은 크리스탈의 분석에 붙잡혀 궁을 쓰지 못하는 사례가 있었다. 피해·생존·궁 충전·사거리 후보를 함께 비교했다. 최종 수치를 적용한 전체 16종 결과는 [최신 상성표](beta7-matchups.md)를 따른다.

## 지정 상성 결과

| 연결 | 이전 | 변경 후 |
|---|---:|---:|
| 민트 → 시안 | 96.94% | 100% |
| 시안 → 핑크 | 98.33% | 100% |
| 퍼플 → 샤르트뢰즈 | 99.44% | 100% |
| 크림슨 → 크리스탈 | 98.89% | 100% |
| 샤르트뢰즈 → 옐로우 | 80.83% | 89.17% |
| 옐로우 → 아이보리 | 99.44% | 99.44% |
| 크리스탈 → 레드 | 98.61% | 99.44% |

지정 연결 네 개를 새로 100%로 복구했다. 각 100%는 360경기 모두 승리한 결과다. 기존 100% 연결을 유지하는 후보를 선택했으며, 미달 연결 세 개는 여전히 목표 미달로 표시한다. 각 캐릭터에게 오직 한 명씩만 100%·0% 상대가 있는 전체 목표 역시 미달이다.

적용 후 전체 43,200경기를 재실행해 **16개 지정 연결 모두 이전 승률 이상**임을 확인했다. 13개 연결이 100%이고 세 개가 미달이다. 전체 결과는 후보 검증 수치와 일치한다. 기존 전투, 아이보리 거리 조준·장판 틱, 궁 재충전, 골드 설치 대기·장판 피해 자동 검사도 통과했다. 브라우저 화면 검증은 수행하지 않았다.

지정 외 상성도 바뀐다. 크리스탈 평균 승률은 76.81%→83.19%, 크림슨은 73.39%→79.83%로 올라갔다. 시안은 27.85%→20.12%, 아이보리는 20.37%→16.76%로 내려갔다. 특정 지정 연결의 복구와 전체 승률 분포는 별도로 확인해야 한다.

## 재현과 원본

- [후보 설정·비교·적용 값](beta7-cycle-repair-options.json)
- `node tools/repair-beta7-cycle.mjs`: 현재 설정을 기준으로 후보 탐색. 추가 단계는 `--refine`, `--finish`로 진행한다.
- `node tools/simulate-beta7-matchups.mjs --repetitions=30`: 적용 설정의 전체 43,200경기와 상성표 갱신.

원본 JSON의 `baseline`은 적용 전 설정, `selected`는 적용한 변경, `config`는 최종 후보 설정이다. 도구를 다시 실행하면 그 시점의 설정으로 새 후보 기록을 만들므로 당시 비교는 저장된 JSON을 따른다.
