# 베타 0.8.44 · 잔여 오류 정리

## 수정

- **첫 경기 랭킹 전송:** 빈 대기열의 비동기 작업이 끝났는데도 처리 중 상태가 남던 문제를 실패 테스트로 재현한 뒤 수정했다. 로그인 직후 첫 경기부터 재접속 없이 전송한다.
- **연속 경기:** 전송 중 새 기록이 추가되어도 최신 대기열을 순서대로 처리한다. 통신 실패는 무한 재시도하지 않고 기록을 저장해 재접속/랭킹 새로고침 때 재시도한다.
- **전송 거절 안내:** 서버에서 기록을 거절하면 조용히 없애는 대신 미반영 건수를 안내한다. 개인 전적과 누적 통계는 유지한다. 경기 시작 정보를 저장하지 못한 경우도 같은 안내를 남긴다.
- **중단 경기:** 재접속으로 중단 경기를 복원할 때 대기 기록을 20개로 줄이던 불일치를 정상 대기열과 같은 100개로 맞추고 중복 ID를 제거했다.
- **공중 사망:** 살몬에게 띄워진 적이 사망하면 공중 상태와 높이를 함께 초기화한다. 기존 3000+착지600, 시간1.2/높이4.5 등의 밸런스 수치는 유지한다.
- **안내:** 로비/시즌 소개의 16종 고정 문구를 실제 캐릭터 수 17종으로 고치고 살몬을 포함했다. 과거 살몬 검증의 1800 피해 기록과 현재 3000 피해 기록을 구분했다.
- **검사:** `npm.cmd run check:beta8`으로 신규 모듈 문법 검사 22개와 기능 검사 13묶음을 함께 실행한다. 브라우저 검증은 별도다.

계정 비밀번호 초기화나 신규 복구 기능은 진행하지 않았다. 기존 사용자 계정/게임 저장 데이터는 이번 검증의 시험 대상으로 사용하지 않았다. 상성 목표·피해·쿨타임의 추가 조정도 하지 않았다.

- `npm.cmd run check:beta8`: 22개 문법 검사, 인증/복구/전적 서버/전적 클라이언트/퀘스트·103단계 보상/살몬/시안 방어 궁/전체 궁 피해/일반·궁 모션/스킨 등급/공유 전투/조준 표시 등 13묶음 통과. 결과 `beta8-maintenance-verification.json`.
- 클라이언트 실패 재현: 수정 전 첫 경기 `/finish` 요청 횟수 0으로 실패, 수정 후 1회 정상 전송. 전송 중 추가 경기·통신 실패 후 재접속·서버 거절 후 개인 기록 보존도 통과.
- Ego space 16, 별도 포트4191 및 메모리 계정 DB. 첫 경기 8.5점이 **재접속 전에** 서버 랭킹에 반영되고 다음 경기 후12점으로 증가. 재접속 중단 경기까지 총3경기/12점 유지.
- 서버 거절 건수 및 개인 전적 유지 안내, 로비17종 문구, 공중 사망 높이2.739→0 확인. 페이지 오류0건. `beta8-maintenance-browser.json`.
- 브라우저 검사는 페이지 내 실제 핸들러/전투 모듈 실행 기준이다. 새 스크린샷이나 수동 포인터 조작 검증은 포함하지 않는다.
