# 일일 승리 보상 — 베타 시즌 1

## 개요

기존의 하루 6회 랜덤 가샤와 수동 수령 버튼은 사용하지 않는다.
기본 게임에서 승리 결과가 기록될 때마다 베타 시즌 재화인 `100 β 크레딧`을 자동 지급한다.

## 지급 규칙

| 항목 | 규칙 |
|---|---|
| 지급 조건 | 게임 결과가 승리로 기록됨 |
| 승리 기준 | 기존 전적 기준과 동일한 `rank <= 4` |
| 1회 지급량 | 100 β 크레딧 |
| 지급 횟수 | 승리할 때마다 1회 |
| 패배 | 지급 없음 |
| 수령 버튼 | 없음, 자동 지급 |

적용 모드:

- 쇼다운
- Chop Wood
- 테이크다운

## 저장 방식

보상은 `localStorage`의 `colorsBetaSeasonTest`에 저장한다.

```json
{
  "credits": 1700,
  "daily": {
    "date": "2026-07-23",
    "winRewards": 2
  }
}
```

- `credits`: 현재 베타 크레딧 잔액
- `daily.date`: 지급 횟수를 집계한 날짜
- `daily.winRewards`: 해당 날짜에 지급된 승리 보상 횟수

승리 처리 함수 `grantBetaDailyWinReward()`가 크레딧과 일일 지급 횟수를 함께 갱신한다.

## UI

`beta-season.html`의 **일일 보상** 화면에서 다음 내용을 표시한다.

- 승리 1회당 지급량
- 오늘 지급 횟수
- 오늘 지급된 총 β 크레딧
- 기본 게임 승리 시 자동 지급된다는 안내

게임 결과 화면에도 `승리 보상 +100 β 크레딧`을 표시한다.

## 주의 사항

- 베타 크레딧은 일반 계정 코인과 별도로 저장된다.
- 여러 탭에서 동시에 게임할 경우 `localStorage`의 마지막 저장값이 우선한다.
- 현재 날짜 문자열은 코드의 공통 날짜 처리 방식과 동일하게 사용한다.

## Acceptance Criteria

- [ ] 승리할 때마다 100 β 크레딧이 한 번 지급된다.
- [ ] 패배하면 지급되지 않는다.
- [ ] 한 경기 결과에서 중복 지급되지 않는다.
- [ ] 쇼다운, Chop Wood, 테이크다운 승리에 적용된다.
- [ ] 일일 보상 화면에 오늘 지급 횟수와 총액이 표시된다.
- [ ] 결과 화면에 획득한 β 크레딧이 표시된다.
- [ ] 새로고침 후에도 크레딧과 지급 횟수가 유지된다.
