# 변신 밸런스 확인 (2026-11-07)

3대3 시뮬레이션(`tools/simulate-beta9-team-modes.mjs`, 40×60 팀 경기장, 18종, 레벨 6, 모드당 600판)을 같은 시드로 **변신 끔 / 켬** 두 번 돌려 비교했다. 원자료: [beta9-transform-balance.json](beta9-transform-balance.json). 변신 켬: `--transforms` (부활·녹아웃 라운드 사이 게이지 이월 포함).

변신 조건: 게이지 궁극기 1.5번 분량, 6초, 공격력 +5%·체력 +20%·보호막 10%, 오렌지 껍질 15개, 샤르트뢰즈 Heaven(표식 + CC 또는 Heaven 재적중 즉사).

## 사용 빈도 (변신 켬, 캐릭터당 모드별 약 190판)

| 항목 | 횟수 |
|---|---|
| 오렌지 변신 | 248 (판당 약 0.6) |
| 샤르트뢰즈 변신 | 206 (판당 약 0.5) |
| 천사 표식 즉사 | 75 |

## 승률 변화

| 캐릭터 | 녹아웃 끔 → 켬 | 젬 그랩 끔 → 켬 |
|---|---|---|
| 오렌지 | 59.0 → 59.5 (+0.5) | 48.9 → 50.5 (+1.6) |
| 샤르트뢰즈 | 48.8 → 50.7 (+1.9) | 52.5 → 50.5 (−2.0) |

캐릭터당 약 190판이라 오차가 ±3.5%p 정도다. 변화가 모두 오차 안이므로 **변신 수치는 조정하지 않는다.**

## 따로 볼 것

- 경기장을 40×60으로 키운 뒤 녹아웃 승률 격차가 크다: 레드 66.3% ~ 핑크 34.3% (32.0%p). 젬 그랩은 21.0%p. 변신과 무관한 경기장 크기 영향이므로 별도 밸런스 조정이 필요하다.
