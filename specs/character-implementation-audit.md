# 메인 캐릭터 기능 대조

메인 시즌 5 기준. 베타 테스트의 별도 밸런스 수치는 메인에 일괄 적용하지 않는다.

| 대상 | 확인 결과 |
|---|---|
| 블루 | 별도 수정 중인 돌진에 충전·입력·벽 반사·넉백 연결 및 검사 추가 |
| 민트 | 얼음·궁극기·투척·체력바 배지 연결 완료, 관련 검사 유지 |
| 핑크 | 부활 무적의 피해 차단 누락, 효과 만료 뒤 예약 부활 취소, 이미 사망한 아군 부활 누락, 팀 없는 상대에게 부활 효과 부여 문제 수정 |
| 그린 | 궁극기 은신 중 공격 시 3초 노출이 빠져 있어 수정 |
| 레드·시안·크림슨·골드·아이보리·샤르트뢰즈 | 메인에 궁극기 설정·발동 경로 존재. 베타와 다른 수치는 별도 시즌 밸런스라 일괄 변경하지 않음 |
| 옐로우 | 전기 회로는 시즌 6 기능. 메인 시즌 5 누락으로 취급하지 않음 |
| 퍼플 | 독성 대도약은 시즌 7 기능. 메인 시즌 5 누락으로 취급하지 않음 |
| 오렌지 | 껍질 회수는 시즌 8 기능. 광역 폭발 25% 설명과 메인 고정 폭발 반경의 관계는 기준 반경 확인이 필요해 수치를 임의로 바꾸지 않음 |

검증은 `npm.cmd run check:characters`, `check:blue`, `check:mint`, `check`로 수행한다.
브라우저 및 멀티플레이 실전 검증은 포함하지 않는다. 발동 경로 존재 확인은 모든 동작의 완전한 검증을 뜻하지 않는다.
