# Computer Use로 메인 업데이트 빠르게 확인하기

다음 프롬프트를 읽고 실행한다.

## 목적

Colors 프로젝트의 메인 시즌 7을 실제 브라우저 화면에서 확인한다. 작성한 코드나 자동 검사 결과를 화면 확인으로 대신하지 않는다.

## 실행

1. 설치된 `computer-use` 스킬과 guidance/confirmations를 읽고 `node_repl`에서 `@oai/sky`를 초기화한다.
2. `sky.list_apps()`로 브라우저의 실제 창을 확인한다. 반환된 창 중 대상이 정확히 하나일 때만 선택한다. 사용자의 기존 탭을 보존하며 새 탭에서 로컬 메인을 연다.
3. 프로젝트를 정적 서버로 제공한다. 서버 시작은 명령 실행 도구로 처리하며, 터미널·실행 창을 Computer Use로 조작하지 않는다.
4. 주소창 이동은 Ctrl+L 같은 단축키를 사용한다. 입력 전 접근성 정보로 포커스를 확인한다.
5. 버튼·메뉴는 `include_screenshot:false, include_text:true`로 확인하고 최신 요소 번호를 이용한다. 3D 모델·장판·공격·전선·맵은 화면 캡처로 확인한다.
6. 상태를 관찰한 호출과 행동하는 호출을 분리한다. 행동은 한 번만 수행하고 즉시 새 상태를 읽는다. 화면이 바뀐 뒤 이전 요소 번호·좌표·캡처 ID를 재사용하지 않는다. 스크린샷과 접근성 정보를 모두 요청하는 것은 둘 다 필요한 경우로 제한한다.
7. 화면에서 시즌 7 문구, 크리스탈·라벤더 선택 항목, 시즌 7 스킨 이름, 젬 그랩 진입을 순서대로 확인한다. 접근 가능한 캐릭터로 훈련장이나 젬 그랩을 시작하여 모델과 HUD를 확인한다. 보유하지 않은 캐릭터·스킨을 검증 목적으로 구매하지 않는다.
8. 실제로 확인한 결과와 확인하지 못한 결과를 구분해서 기록한다. 로그인·계정 생성이나 권한 승인 화면이 필요하면 해당 단계에서 사용자에게 맡긴다. 광고·보안 경고·다른 앱을 조작하지 않는다.

## 속도와 복구

- 불필요한 앱 목록 재조회, 중복 캡처, 고정된 긴 대기를 줄인다. 접근성으로 해결되는 단계는 이미지 캡처를 생략한다.
- 화면이나 요소가 바뀌는 행동 후에는 반드시 새 상태를 읽는다. 속도를 위해 검증을 생략하거나 여러 클릭을 추측해서 연속 실행하지 않는다.
- 가벼운 조회가 시간 초과하면 2초 뒤 한 번 재시도한다. 다시 실패하면 세션을 초기화하고 한 번만 더 시도한다. 계속 실패하면 정확한 오류를 보고하고 중단한다.
