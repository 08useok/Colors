# 베타 시즌 5 앱 전환 기획

## Summary

베타 시즌 5부터 현재 웹 게임을 설치형 앱으로 제공한다. 기존 게임 규칙과 시즌 콘텐츠는 유지하고, 앱 실행·업데이트·화면 전환·성능을 앱 환경에 맞게 정리한다.

## JTBD

플레이어가 사이트 주소나 브라우저 상태에 의존하지 않고 앱을 실행해 바로 로비에 진입하고, 캐릭터 선택과 전투를 안정적으로 이용할 수 있어야 한다.

## Scope

- 기존 로비, 캐릭터 선택, 훈련장, 쇼다운 전투를 앱에서 실행
- 기존 GLB 모델, 이펙트, 시즌 데이터 재사용
- 앱 시작 화면과 로딩 상태 추가
- 앱 내에서 시즌 버전과 업데이트 상태 표시
- PC 우선 지원, 이후 모바일 대응을 고려한 입력 구조 유지
- 웹과 앱에서 공통으로 사용할 게임 데이터·전투 로직 분리

## Non-goals

- 베타 시즌 5에서 새로운 전투 규칙을 동시에 대규모로 추가하지 않는다.
- 계정·결제 시스템을 앱 전용으로 재설계하지 않는다.
- 기존 웹 버전을 즉시 폐기하지 않는다.

## 앱 방향

1. 1차 목표는 PC 설치형 앱이다.
2. 기존 웹 렌더링 구조를 최대한 재사용하고, 앱 쉘은 게임 화면을 안정적으로 감싸는 방식으로 구성한다.
3. 앱 실행 후 `로딩 화면 → 로비 → 캐릭터 선택/훈련장/전투` 흐름을 고정한다.
4. 브라우저 주소·새로고침에 의존하는 상태 전환을 앱 상태로 관리한다.

## 화면 요구사항

### 시작 화면

- 앱 아이콘과 `베타 시즌 5` 표시
- 게임 리소스 로딩 진행률 표시
- 로딩 실패 시 재시도 버튼과 원인 안내
- GLB 로딩 전 임시 모델이 노출되지 않아야 한다.

### 로비

- 시즌 배경과 쇼다운 맵 미리보기 표시
- 중앙에 선택 캐릭터 미리보기 표시
- 생존 인원·체력 등 로비 정보 표시
- 캐릭터 버튼을 누르면 납작한 중간 패널 없이 캐릭터 UI가 즉시 전체 화면으로 열린다.

### 캐릭터 선택

- 캐릭터 미리보기와 로비 미리보기를 분리한다.
- 선택한 캐릭터의 GLB와 스킨을 표시한다.
- GLB 로딩 중에는 로딩 상태만 표시하고 이전 캐릭터나 임시 모델을 잠깐 보여주지 않는다.
- 뒤로 가기 시 로비 화면과 선택 상태를 복원한다.

### 훈련장

- 캐릭터 선택 버튼 옆의 훈련장 버튼으로 진입한다.
- AI 플레이어는 없고, 훈련 봇만 배치한다.
- 거대 봇과 짤짤이 봇을 제공한다.
- 쇼다운 테마와 별도의 훈련장 환경을 유지한다.

## 기술 요구사항

- 게임 로직과 렌더링 로직은 앱 쉘과 분리한다.
- 입력은 마우스·키보드 기반으로 먼저 안정화하고, 터치 입력 확장 지점을 남긴다.
- GLB·텍스처·오디오 자산은 필요한 시점에 로드하고 캐시한다.
- 앱 재실행 후에도 선택 캐릭터·스킨·언어 등 기존 로컬 상태를 복원한다.
- 버전 불일치 또는 업데이트 실패 시 플레이를 시작하지 않고 안내한다.
- 창 크기 변경과 전체 화면 전환에서 HUD가 잘리지 않아야 한다.

## 업데이트 정책

- 시즌 버전은 `Beta Season 5`로 표시한다.
- 앱 업데이트와 게임 콘텐츠 업데이트를 구분해 표시한다.
- 업데이트 확인 실패 시 마지막으로 검증된 콘텐츠를 사용하고, 필요한 경우 재시도한다.
- 배포 전에는 웹 버전과 앱 버전의 핵심 전투 로직 결과가 일치해야 한다.

## 개발 순서

1. 기획: 앱 대상 플랫폼과 실행 흐름 확정
2. 개발: 앱 쉘, 시작 화면, 상태 복원, 기존 화면 연결
3. 개발: GLB/리소스 로딩 및 캐시 안정화
4. 디자인: 앱 시작 화면과 로딩·오류 상태
5. 검증: 로비·캐릭터 선택·훈련장·전투 회귀 테스트
6. 배포: 베타 채널에 앱 빌드 배포

## Acceptance Criteria

- 앱을 실행하면 5초 이내에 로딩 상태가 표시된다.
- 정상 자산이 준비되기 전 임시 캐릭터 모델이 화면에 나타나지 않는다.
- 로비에서 캐릭터 버튼을 누르면 중간 납작 패널 없이 캐릭터 UI가 즉시 전체 화면으로 전환된다.
- 캐릭터 선택 후 로비로 돌아오면 캐릭터와 스킨 선택이 유지된다.
- 훈련장 진입 시 AI 전투원이 생성되지 않고 훈련 봇만 표시된다.
- 앱 재실행 후 마지막 선택 캐릭터와 스킨이 복원된다.
- 창 크기를 바꾸거나 전체 화면으로 전환해도 주요 HUD가 화면 밖으로 밀리지 않는다.
- 로딩 실패·업데이트 실패 시 사용자가 재시도할 수 있다.
- 기존 웹 버전의 핵심 전투 동작과 앱 버전의 결과가 일치한다.

## Validation

- PC 설치·실행·종료·재실행 테스트
- 느린 네트워크에서 GLB와 텍스처 로딩 테스트
- 캐릭터 8종 및 주요 스킨 미리보기 테스트
- 로비 → 캐릭터 선택 → 로비 → 훈련장 → 전투 전환 테스트
- 창 크기 1280×720, 1920×1080, 세로형 좁은 창 테스트
- 앱 업데이트 성공·실패·재시도 테스트

## 미결정 사항

- 1차 앱 플랫폼: Windows 전용 또는 Windows/macOS 동시 지원
- 앱 패키징 방식: 기존 웹 런타임 포장 방식 또는 별도 네이티브 쉘
- 자동 업데이트 제공 여부와 베타 배포 채널
- 모바일 앱을 베타 시즌 5에 포함할지 여부
