# 베타 전용 벽 모델

- 원본: `Meshy_AI__1004085325_texture_fbx.zip`.
- 원본 보관: `wall.fbx`, `wall.png`, `wall_normal.png`, `wall_metallic.png`, `wall_roughness.png`.
- 게임용: `wall.glb` (6,000 삼각형, 1,024px 텍스처 내장, 약 4.77 MB).
- 원본 면 수: 60,906 삼각형. 원본 모델과 텍스처는 수정하지 않았다.
- Three.js 좌표 기준 크기: 가로 1.899, 높이 1.529, 두께 0.475. Y축이 위쪽이다.
- 적용: 베타 HTML의 로비 방·복도 경계벽 36개, 엄폐벽 7개, 쇼다운 벽 9개, 젬 그랩 벽 20개(내부 엄폐벽 16개 + 외곽벽 4개).
- 가로벽은 X축으로 이어 붙이고 세로벽은 Y축을 중심으로 90도 회전한다.
- 벽 길이에 맞게 여러 조각을 이어 붙이며, 각 벽의 높이·두께·충돌 범위에 맞춘다.
- 바닥·다리·장식 기둥은 기존 모델을 사용한다.
- 충돌용 원래 메시에 외형을 붙이므로 벽 파괴 및 모드 표시 처리를 함께 따른다.
- 에셋은 한 번만 불러오고 조각의 지오메트리와 텍스처를 공유한다.
- 변환 재실행: Blender에서 `tools/prepare-beta-wall.py`를 백그라운드로 실행한다.
